# 最小对接包

2026-09-25开工版；11月4日提交。可以直接发给FPGA和硬件队友，先启动可调整采集原型。

- 先读[开工与对接约定](开工与对接约定.md)：分工、数据格式、硬件调整边界及回传标准。
- 按[采集清单](真实十六通道采集清单.md)先录底噪、单源，再宽间隔三源。
- 回填[设备与首批录音信息](设备与首批录音信息.json)和[通道与坐标表](通道与坐标回填.csv)。CSV可用Excel打开；空白待填，不是默认坐标。
- [布局候选](布局候选_非定版.csv)仅供可调样机参考，禁止当作已定型PCB或实际测量值。

本包不包含RTL、最终位宽/FFT配置、波束权重或板端逐位参考向量；这些在采集链和实际IP配置确认后交付。本包也不宣称实录、综合或复杂环境分离已验收。

本目录是项目docs/规划与进度/队友开工与最小对接约定.md及采集清单的日期快照；队友填写模板后另存回传副本即可。后续规则修改由算法侧提供新日期/版本包，不覆盖已发版本。无需接收完整代码仓库才能阅读本包。
