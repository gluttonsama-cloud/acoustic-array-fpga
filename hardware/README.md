## 正式交付清单

- 采样/通道顺序、时钟关系、PDM编码和前端滤波规格。
- 校准、窗函数、steering、波束权重等系数及其生成版本。
- PCM→窗→FFT→复乘累加→IFFT→OLA各级输入与期望输出。
- 每一级整数类型、位宽、缩放、舍入、溢出、排列及容差。
- 权重更新协议：双bank或等效一致性保证、生效帧、目标ID、平滑规则。
- 配置/文件SHA-256、生成命令、输入标识和预期状态。
- 时序、资源、吞吐与板端延迟报告索引；真实工程参数必须与参考模型一致。

## 第一版计算与存储预算示例

以下是自行推导的量级估算，非综合结果。假设 N=512、H=256、48 kHz、16输入、3输出、单边谱257频点、64扫描方向；每复数系数用两个16-bit分量，仅用于估算。

- 每秒187.5帧；16个前向FFT加3个IFFT共3562.5次512点变换/秒，不含重构双边谱等开销。
- 三路波束每秒约 187.5×257×16×3=2,313,000 次复数MAC。
- 若64方向每帧扫描全部257频点，每秒约49,344,000次复数MAC；实际可限制频带和扫描更新率，需要精度对照。
- 三输出权重单bank约257×16×3×4=49,344 bytes，双bank约98,688 bytes。
- 全64方向steering表约257×16×64×4=1,052,672 bytes；不能未经核对就假定全部片上存储可行。
- 16路48 kHz PCM以每样本32-bit承载时，原始有效载荷3,072,000 bytes/s，不含传输协议和复制开销。

一复数MAC不能直接等同一个DSP或一个时钟周期。还须计入实乘加分解、位宽、读写端口、FFT架构、缓冲、AXI/DMA与更新冲突。优先比较时分复用、系数现场生成和选频扫描，而非盲目全并行。

FFT缩放与架构参考AMD官方 [PG109 Architecture Options](https://docs.amd.com/r/en-US/pg109-xfft/Architecture-Options) 和 [Forward/Inverse and Scaling Schedule](https://docs.amd.com/r/en-US/pg109-xfft/Forward/Inverse-and-Scaling-Schedule)，访问2026-09-19。文档版本不自动等于队友安装的IP版本，须另外确认。
