## 目标与范围

构建基于 16 麦线阵的多声源实时空间分离与定向增强系统，交付三路目标音频、方向/跟踪状态、可复现实验报告和 FPGA 对照资料。多声源实时空间分离与定向拾音是核心交付，复杂噪声下弱声增强是重点演示；呼救/敲击及搜救是应用示例，不限死为搜救产品。核心目标不随单个增强演示的困难而擅自转向。应用方向与验证优先级见[主应用场景与转向条件](主应用场景与转向条件.md)；尚不宣称已经具备灾害搜救可靠性。

高要求体现在效果、边界、复现和硬件实现共同达标，而不是无条件承诺三人完全分离或同时堆入深度学习。

- 基线：DAS，多方向空间谱，给定方向的最小范数约束波束形成。
- 主线：宽带约束波束形成，误差稳健性、自动 DOA、稳定目标关联、权重平滑。
- 候选增强：SRP-PHAT、MVDR/LCMV、约束软化或角度区间鲁棒性、后滤波。
- 离线研究对照：AuxIVA/ILRMA 等盲分离方法，先比较效果与代价，再决定是否值得迁移。
- 暂不承诺：同方向说话人分离、完整三维定位、任意混响/距离、全频带同等分离能力、任意声源数、端到端神经网络部署。

## 基础参数与冻结策略

原始阵列参数见 references/input，机器可读副本见 configs/array/ula16_v1.json。16 麦、48 kHz、3.072 MHz PDM、64 倍抽取、30.48 mm 间距、457.2 mm 孔径构成当前基线。

FFT 比较 256/512 点、帧移 N/2；Hann 为原始候选窗，必须分别确定分析窗、合成窗和归一化。主要空间处理频带约 500 Hz～5 kHz。频带外策略也必须评价，不能删除频带后只报漂亮指标。

几何与采样参数修改写 ADR 并重新验证相关结果；第二周冻结的是有证据的第一版实现规格。当前不假定麦克风型号、FPGA 完整型号、IP 版本、PDM 编码方式和 CIC 阶数已经确认。

## 第一轮实现顺序

1. 建立轻量 Python 包、经过执行验证的安装/实验命令；选取最小必要依赖并锁定。
2. 实现配置校验和坐标/延迟解析案例；用独立生成方法防止同一符号错误在仿真与波束里相互抵消。
3. 跑通随机信号、脉冲、短输入的流式 STFT/ISTFT；再接入音频。
4. 单源、双源、三源依次验证，先给定真实方向；保存各分量供评价。
5. 引入约束波束形成；保留 DAS 和单麦基线，生成第一份可复现报告。
6. 注入 DOA、增益、延迟、位置误差和混响，判定下一步算法选择。

## 交付定义

每个算法增量至少包含：实现、适用条件、独立正确性检查、配置、实际运行命令、输入/输出索引、指标和限制。涉及可部署分支时增加计算量、状态量、缓存量、位宽风险和模块交接说明。

最终不是交付一个只在特定音频上能运行的 notebook；必须有包内实现、可重复实验入口、回归场景和硬件数据契约。Notebook 可用于探索，不作为唯一可执行来源。
