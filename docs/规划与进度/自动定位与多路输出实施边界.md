# 自动定位与多路输出实施边界

> 文档类别：规划与进度｜状态：W4静态方向参考已实现，自动多路输出未完成。[返回文档索引](../文档索引.md)。

## 要完成的核心闭环

输入同步多通道PCM → 估计候选方向及可信度 → 选择/关联目标 → 根据估计方向形成多个音频输出。人工给定方向保留为控制组，不能送入自动方向分支；同输入比较定位错误造成的分离损失。

第一增量只闭合静态场景，不把移动跟踪、救援语义识别或未知三维空间全部混在一起。现有前半平面与水平角约定继续使用；相邻多个网格点不能当成不同声源。

## 模块边界

- localization只读取多通道谱帧、真实麦坐标和配置；输出方向候选、得分、候选状态。不得读取干净源、参考活动掩码或真实源方向。
- 使用DAS扫描作为基线，SRP-PHAT作为既有研究支持的候选；先验证符号、参考通道、时延和静音行为再接真实语音。PHAT弱能量保护及有效频点应显式记录。
- 峰选择使用局部峰、角距抑制和显式阈值；无可信峰允许返回空，不为了保持三路而补虚构方向。已知声源数量分支只作控制，未知数量分支另报漏检/虚警。
- 多路输出先静态锁定候选；同一输入分别使用真实方向与估计方向，评分与试听对齐。身份跟踪和移动权重切换另作后续增量，不偷用未来帧。

## 评价与硬件联系

定位报告角误差、匹配规则、召回、虚警与静音输出；增强报告各目标全带/带内损失，不能只以峰图判断成功。三路已知方向都无法有效增强的条件，定位成功也不能将其写成分离通过。

主路不能获得真实距离；远场假设或有限距离候选网格需在实验前确定，并与准确距离的控制结果分开。第一版先锁定固定搜索范围/频带，后续若改动须保留原配置和失败记录。

计算预算按有效频点×麦对/通道×扫描点×更新率估计，权重更新与每帧音频执行分离。减少扫描更新率是候选工程手段，但真实板端预算仍需综合与运行证据。

## 启动条件与退出

W3四条件确认完成后结束布局扫描，使用锁定阵列进入W4；若布局优势不稳定，保留baseline对照而非继续寻找更多阵型。W4第一包只要求混合信号输入到静态候选方向的可运行参考、独立解析检查和代表场景结果；下一包再将估计方向接入多路音频。不得将本规格文档标成已完成自动定位。


一手资料及读取范围见[W4启动资料核验](../参考研究/算法论文与产品调研.md)，项目与外部库角度坐标约定必须显式转换。

## 首轮固定开发协议（运行前冻结，2026-09-24）

配置为configs/experiments/w4_static.json：只使用W3锁定交错布局的四个确认条件，读取最初3秒混合PCM的完整512点帧（不补尾、不读取未来样本）；固定500～5000Hz、前半平面1°网格、远场假设。算法不读真实距离、方向、干净分量或活动标签。重建器使用父归档生成原输入，评分器在扫描后读取方向真值。

DAS输入按共同复数分量最大值缩放；最低分数0.001。SRP-PHAT先跨帧平均麦对互谱再做PHAT，最低相位一致性分数0.1。相对能量保护1e-8，局部峰最小间隔10°，输出上限3个但不强制输出3个；这仍有容量先验，不称完全无先验的未知源数估计。阈值为未校准的开发设定，不按本轮成绩改写；不作为可信概率。

按5°容差作一对一匹配，先最大匹配数、再最小角误差；同时报漏检、虚警和仅匹配项MAE，禁止用低MAE掩盖漏检。该固定四条件只作下一步方法选择，不算独立验收。若SRP-PHAT覆盖优于DAS，优先接多路输出；若二者漏检均明显，保留结果，先解决候选覆盖，不直接接成成功产品演示。完成一次即停止追加网格。远场扫描的距离失配是已知边界。

执行结果：首轮已完成，见[静态验证报告](../实验与验证/静态自动定位首轮验证.md)。SRP候选覆盖不足，按停止条件进入一次有界候选修正，不将第一包代码完成等同产品通过。

## 短时修正预注册（2026-09-24，真实场景运行前）

待决问题：逐帧PHAT和短时候选支持度能否改善上一版7/12匹配、4虚警，并达到音频接入开发关口。固定配置configs/experiments/w4_temporal.json，不改阵型、源素材、前三秒输入、频带或方向网格，不读取真值筛选方向。

唯一新候选：先逐帧归一化麦对互谱，再每20完整帧（约107ms更新步距）平均SRP图；丢弃不足20帧的尾部。每图局部峰至少0.1、10°邻域显著性至少0.05，显著性为峰值减去左右局部谷底较高者，边界用唯一可见侧，不直接禁止端射。显著性筛选后做10°角距抑制，每块最多3峰。候选对3°邻域投三角票，每块相同方向最多1票，跨所有完整块（包括静音块）取平均，最终至少10%支持、间隔10°、最多3路。这是有界工程组合，不声称复现某篇论文或概率置信度。

先通过解析单源、交替多源、真实端射、静音与独立噪声检查；阈值是预定工程值，仍非真实环境虚警标定。每块丢尾与原静态561帧相比需明确：候选使用560帧，原基线仍用561帧（并记录一个560帧静态对照，区分丢尾影响）。真实开发场景只跑一次固定四条件；通过条件为匹配至少9/12、虚警不超过2、每条件匹配不低于原基线。全部满足才进入估计方向多路音频；不满足保留失败并停止该候选的阈值扫描。

运行前解析检查修正：真实16麦/30.48mm间距在±90°端射处角度分辨力降低，10°邻域的下降不足0.05，会错误排除完全相干的真实端射。故边界峰显著性使用固定30°单侧邻域，内部仍10°；在真实房间运行前固定，并以实际阵列解析端射验证，不用更大孔径测试掩盖问题。其余阈值与通过门槛不变。

## 时频/子带候选预注册（2026-09-24，场景运行前）

待决问题：不再从一张多源宽带图选三峰，而是让每个短时子带给出一个主导方向，看跨时间/子带直方图能否恢复两个侧向源。依据是Pavlidi等的时频单源主导区思路与SRP综述中的子带聚类路线；本实现为自主简化工程候选，不声称论文复现。

固定配置为`configs/experiments/w4_subband.json`：20帧短块，500～5000Hz内连续4个FFT频点为一子带；不完整尾块和尾子带丢弃并记录。每帧/频点先PHAT，子带图只保留一个主导峰。块内子带能量门限为该块最大子带的`1e-5`，以保留解析案例中相差40dB功率但频带互斥的弱源，噪声仍由空间一致性关口拒绝；空间分数至少0.2，显著性至少0.05，内部10°邻域、边界30°单侧邻域。每个接受子带向3°邻域投三角票，以全部完整块×完整子带数为分母；最终支持率至少5%、方向间隔10°、最多3路但不强制补足。得分不是概率。

解析验收覆盖单源符号、三源互斥子带、不等增益、实际阵列端射、显式坐标、静音、独立噪声、极端数值及丢尾。通过解析检查后，只对同四个开发条件运行一次。关口与前一候选一致：至少9/12匹配、虚警不超过2，且每条件不低于静态基线匹配数。不通过就停止SRP峰阈值类修补，不据成绩修改本轮参数。

执行结果：子带候选仅匹配4/12、虚警0，侧向真值在336个候选单元中多数为零票；停止SRP峰值与阈值修补。详见[子带主导方向对照](../实验与验证/子带主导方向对照.md)。

## MUSIC外部基线预注册（2026-09-24，场景运行前）

待决问题：在不改变阵列、混响、语料和前三秒输入的情况下，显式三源子空间模型能否稳定恢复当前SRP遗漏的侧向源。该轮用于区分“当前SRP候选不足”和“当前阵列、RT0.4及三源同时活动的联合边界”，不是板端候选实现。

固定配置为`configs/experiments/w4_music.json`，外部参考固定Pyroomacoustics 0.10.1。主方法NormMUSIC，普通MUSIC作为同输入诊断；两者均显式`num_sources=3`，使用500～5000Hz、前半平面1°网格、前三秒完整谱帧和10°峰间隔。输入从项目`[frame,frequency,mic]`转换为库`[mic,frequency,snapshot]`；项目从`+y`向`+x`的角度`theta`显式转换为库从`+x`起算的`phi=90°-theta`。真实方向只在输出后评分，不进入协方差、频点或峰选择。

沿用静态SRP基线及5°一对一匹配。主方法通过条件仍为至少9/12匹配、虚警不超过2，且每个条件匹配数不低于静态SRP；普通MUSIC只报告，不参与是否接入音频的主判定。只运行一次固定四条件，不按结果修改源数、频带或峰规则。NormMUSIC通过才进入估计方向多路音频；若未通过，停止在这四个仿真条件上追加定位算法，并转为联合边界拆分及真实16通道采集设计。
