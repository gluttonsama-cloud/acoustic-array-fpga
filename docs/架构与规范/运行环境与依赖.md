# 依赖与复现环境

> 文档类别：架构与规范｜状态：现行维护文档。[返回文档索引](../文档索引.md)。

验证环境：Windows x64、CPython 3.12.10。本地虚拟环境为项目内.venv。requirements-lock.txt固定本轮全部运行/构建/测试依赖；这是该平台的精确版本清单，尚不是带发行包hash的跨平台锁文件。

| 依赖 | 本轮版本 | 用途 | 许可核验 |
|---|---|---|---|
| NumPy | 1.26.4 | 数组、FFT、随机数和基础线性代数 | 安装包metadata内BSD许可；二进制打包组件另含声明 |
| SciPy | 1.17.1 | 窗函数、滤波、卷积、WAV和独立参考 | 安装包metadata内BSD许可；随轮子附带第三方声明 |
| pytest | 9.0.3 | 解析/集成/回归测试 | metadata标记MIT |
| Ruff | 0.16.8 | 静态检查和格式 | metadata标记MIT |
| SoundFile | 0.13.1 | M2解码OGG语音 | 官方文档标记BSD，底层libsndfile为LGPL；发行轮子的许可声明需保留 |
| setuptools / wheel | 83.0.0 / 0.48.0 | 打包及editable安装 | 构建工具，不复制到算法源码 |

本轮核验采用安装包metadata与先前官方来源；未复制任何第三方源码进仓库，未下载公开语音数据集。其他传递工具依赖固定在锁文件；公开再分发二进制前还需保留其各自许可声明。

ODAS暂未引入实际运行依赖。Pyroomacoustics仅作为可选`doa`依赖用于W4离线MUSIC基线，不进入主运行依赖，也不等于FPGA部署实现。

M2新增SoundFile及其cffi/pycparser依赖，版本固定在requirements-lock.txt。三份语音素材不是Python依赖，另由显式下载脚本和数据manifest管理；自动化测试使用本地产生的小信号，不依赖联网或真实语料缓存。

```powershell
python -m venv .venv
.venv/Scripts/python.exe -m pip install -r requirements-lock.txt
.venv/Scripts/python.exe -m pip install -e . --no-build-isolation --no-deps
.venv/Scripts/python.exe -m pytest -q
.venv/Scripts/python.exe -m ruff check src tests
.venv/Scripts/python.exe -m acoustic_array.pipelines.cli --config configs/experiments/m1_das.json
.venv/Scripts/python.exe tools/download_speech_examples.py
.venv/Scripts/python.exe -m acoustic_array.pipelines.speech_experiment --config configs/experiments/m2_speech_development.json
```

运行命令的工作目录为项目根目录。配置中的array_config按实验配置文件所在目录解析，结果目录按命令工作目录解析。Windows之外尚未实际验证；pyproject支持范围不是每个平台已通过测试的声明。

2026-09-21：本地包已升级0.3.2，无新增第三方依赖；editable安装、wheel构建与pip check通过。
