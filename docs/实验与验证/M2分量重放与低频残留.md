# M2 分量重放与残留诊断

> 文档类别：实验与验证｜状态：历史阶段记录；不代表当前项目状态。[返回文档索引](../文档索引.md)。

日期：2026-09-20；版本v0.3.1。新增物理分量评价与可复现审计入口，波束算法及默认参数未变。本轮仍是开发数据诊断，不是正式B1验收。

## 主要发现

100 Hz扩频候选中，中间一路的低频串音是当前主要限制：输出全带SIR只有1.37 dB，而输出SNR约37.18 dB；残留其他说话人干扰的99.76%功率位于500 Hz以下。目标自身在该理想正前方几何下几乎未失真，因此优先处理低频干扰，而不是继续增加普通降噪。

另一个代价也得到确认：扩频后两侧目标的目标单独输出SI-SDR由约38.00/35.63 dB降到19.27/20.76 dB。即使分离总成绩改善，也不能忽略目标保真度下降。尚不能仅据本实验把下降全部归因于某一窗长或某个频点。

## 定义与验证

读取先前run的输入分量与已保存固定权重，逐源、逐噪声重放同一StreamingBeamformer；不重新求解权重，不用干净源优化输出。各源输出与噪声相加，和原混合输出的最大相对L2误差为3.995e−16。

- 物理SIR=10log10(目标分量功率/其他源求和波形功率)，先求和再算能量，保留交叉项；它不是BSS Eval投影SIR，也不是SI-SDR。
- SNR单独用目标与麦噪声分量计算，不把其他说话人叫作麦噪声。
- 保留原MIC7参考、同样裁剪、全段评价、无活动掩码；带内仍用同一500～5000 Hz Butterworth滤波后裁剪。
- 目标保真度：只比较目标单独传播参考和目标单独波束输出的零均值SI-SDR；不含其他说话人。
- 频段功率用裁剪后全段矩形DFT的Parseval分解，不去均值，包含DC，正确计数Nyquist；分为[0,500)、[500,5000]、(5000,Nyquist]。此诊断不是上面的滤波带内指标，不能直接混用。
- 静音、零干扰和零噪声用null与明确状态记录，不伪造有限封顶分数。中间目标保真度约305 dB仅反映双精度舍入误差，不能解释为硬件动态范围或实际音质。

## 低噪声、正确方向结果

以下均为输出绝对比值，不是改善量，目标顺序−45°/0°/+50°。

| 方案 | 输出全带SIR dB | 输出全带SNR dB | 各路干扰中500 Hz以下占比 |
|---|---|---|---|
| 原500 Hz | 1.946 / −0.357 / −0.150 | 38.054 / 38.045 / 38.024 | 98.85% / 99.03% / 99.44% |
| 100 Hz候选 | 10.468 / 1.374 / 5.328 | 36.328 / 37.185 / 37.102 | 99.07% / 99.76% / 99.94% |

候选中间一路目标功率0.001614、其他说话人总和功率0.001176、麦噪声功率3.086e−7（归一化PCM均方）。干扰约为噪声的3811倍。这是在当前理想场景下对残留来源的直接分量证据，不代表真实房间或实录。

高噪声候选重放中，SIR保持不变，三路SNR分别为16.328/17.185/17.102 dB，恰比低噪声下降20 dB，符合固定权重和十倍噪声幅度的预期。该一致性不证明自适应或硬件系统的稳健性。

## 下一步
