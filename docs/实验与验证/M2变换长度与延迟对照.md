# M2 FFT长度、保真度与延迟对照

> 文档类别：实验与验证｜状态：历史阶段记录；不代表当前项目状态。[返回文档索引](../文档索引.md)。

实验日期：2026-09-20；归档：2026-09-21。算法包仍为v0.3.1，本轮只新增配置、实验与文档。结论是保留512和1024点继续比较，2048点暂作研究对照；默认配置未改变。

## 结果

同一组10秒开发语音，三源方向−45°/0°/+50°，16麦理想远场，约束频带配置100～5000 Hz。以下均为无方向偏差、噪声RMS0.002的结果，三个数字依次对应三路目标。

| FFT / WNG门槛 | 全带SI-SDRi dB | 500～5000 Hz SI-SDRi dB | 两侧目标单独输出SI-SDR dB |
|---|---|---|---|
| 512 / −10 dB | 12.836 / 4.305 / 8.193 | 32.260 / 25.885 / 28.879 | 19.275 / 20.765 |
| 1024 / −10 dB | 10.359 / 4.672 / 5.997 | 39.143 / 33.039 / 37.034 | 25.826 / 27.695 |
| 2048 / −10 dB | 10.996 / 4.377 / 6.442 | 42.561 / 38.352 / 40.358 | 30.760 / 33.679 |
| 1024 / 0 dB | 6.332 / 3.042 / 3.449 | 38.779 / 33.032 / 36.883 | 37.541 / 32.204 |

更长FFT提高了本例带内结果和两侧目标保真度，但全带分离并不单调改善。1024点相对512点的两侧目标保真度提升约6.55/6.93 dB，同时这两路全带SI-SDRi降低。WNG门槛升至0 dB进一步保护目标，却牺牲低频干扰抑制，不能只按单一指标选参数。中间目标的单独输出约305 dB是理想正前方模型中的浮点舍入水平，不作实际音质或硬件动态范围成绩。

共同方向偏差−5/0/+5°、全部三路的最低全带SI-SDRi分别为：512点4.096 dB，1024点4.409 dB，2048点4.147 dB，1024点/0 dB门槛2.824 dB。约0.31 dB的最差值差异不足以从这一组素材宣布1024点具有普遍优势。

## 低频网格与保护回退

所有配置都写100 Hz下限，但频率网格不同。下表是0°方向偏差时的实际状态，单位Hz。

| FFT / WNG门槛 | 首候选频点 | 三路首个成功约束频点 | 回退频点×输出数 |
|---|---:|---|---:|
| 512 / −10 dB | 187.5 | 187.5 / 281.25 / 187.5 | 1 |
| 1024 / −10 dB | 140.625 | 187.5 / 234.375 / 187.5 | 4 |
| 2048 / −10 dB | 117.1875 | 164.0625 / 234.375 / 164.0625 | 9 |
| 1024 / 0 dB | 140.625 | 328.125 / 375 / 328.125 | 13 |

低频回退到DAS，各规格实际处理的低频网格和过渡行为不同；更长窗也改变子带近似与时域重建。以上数据能说明比较中有多个变化因素，不能单凭本实验把全部非单调结果归因于回退数量。不同FFT频点数不同，回退数量本身也不是同尺度失败率。

## 高噪声结果

1024/2048点另测噪声RMS0.02，即幅度10倍、功率增加20 dB，仅正确方向，WNG门槛−10 dB。此处报告输出绝对全带SI-SDR，避免因输入基线变差而误读SI-SDRi。

| FFT | 低噪声输出SI-SDR dB | 高噪声输出SI-SDR dB | 高噪声物理SNR dB |
|---|---|---|---|
| 1024 | 7.361 / 1.768 / 2.976 | 6.909 / 1.630 / 2.813 | 16.826 / 16.680 / 17.116 |
| 2048 | 7.998 / 1.473 / 3.421 | 7.447 / 1.346 / 3.229 | 16.595 / 16.795 / 16.778 |

同权重分量重放显示SIR不随独立噪声幅度变化、SNR下降20 dB，符合线性模型预期。高噪声下两规格仍各有优劣；这不是通道误差、混响或自动定位稳健性证明。512点高噪声结果见此前[分量报告](M2分量重放与低频残留.md)，未把旧结果重复计入本轮新增实验数。

## FPGA代价与延迟

固定16输入、3输出、48 kHz、帧移N/2。以下是模型预算，不是Vivado综合或板端测量。

| FFT | 频率间隔Hz | 首个完整有效输出块采样等待ms | 帧移ms | 单套复数权重数量 | 波束复数MAC/s |
|---|---:|---:|---:|---:|---:|
| 512 | 93.75 | 10.667 | 5.333 | 12336 | 2313000 |
| 1024 | 46.875 | 21.333 | 10.667 | 24624 | 2308500 |
| 2048 | 23.4375 | 42.667 | 21.333 | 49200 | 2306250 |

权重数量=(N/2+1)×16×3，MAC率再乘Fs/(N/2)，包含DC/Nyquist按一般复数操作预算。权重位宽未冻结，双缓冲等还需额外存储；FFT本身及重叠相加成本不包含在此MAC数内。延长FFT虽然降低帧率，权重和帧状态空间却约成倍增加，FFT计算成本也不能由该MAC表推断不变。

42.667 ms只是2048点的采样等待，不含前端滤波、计算、调度及输出缓冲。相对50 ms端到端目标，仅剩约7.33 ms预算，因此暂不将2048作为部署首选。此处不能作为任何规格已满足实时目标的证据。

## 复现与验证

四组主对照、两组压力测试共6个语音run和6个分量run；84条目标混合评价与18条名义方向分量评价均来自同一组语音，不是独立场景验收。相同噪声等级内input.npz哈希完全相同，保持相同裁剪、评价频带、源音量和种子。正式活动掩码、独立保留语料、混响、通道误差和自动DOA均未加入。

在项目根目录复现指定配置：

```powershell
.venv/Scripts/python.exe -m acoustic_array.pipelines.speech_experiment --config configs/experiments/m2_fft_1024_wng_minus10.json
# 将上一步打印的新run路径填入下一条命令：
.venv/Scripts/python.exe -m acoustic_array.pipelines.component_experiment --parent-run artifacts/runs/speech_20260920T060927_725157Z_8140a9be
```

第二条所列路径为本轮已归档例子。六份配置均位于configs/experiments/m2_fft_*.json。完整映射见[run索引](../../artifacts/validation/m2-fft-index.json)；指标、回退频点、同输入与源码/产物核验见[摘要](../../artifacts/validation/m2-fft-summary.json)。语料归属、许可和修改说明随每个语音run/REPORT.md保存。

- 512/1024/2048点额外执行16通道随机输入、MIC7恒等输出检查，最大相对L2误差2.484e−16；[数值检查与预算](../../artifacts/validation/m2-fft-numerical-checks.json)。
- 六组同权重分量重建最大相对L2误差4.151e−16；源码和产物哈希已核验。
- 核心代码未改，本轮未重复计作新增112项回归通过；已有测试证据见v0.3.1报告。
- 独立审查确认首块等待解释，指出ADR中高噪声组描述遗漏，已修正；随后因服务用量限制中断，最终报告未完成独立复核。其余数值与链接由主代理核验，不记作审查通过。

## 下一步决策

保留512/1024作为后续稳健性与语料扩展比较对象，2048保留为研究对照，默认配置不改。停止仅在三段开发语音上继续挑最优参数；下一步优先独立方向/通道误差与独立语料，统一用分离、目标保真度、噪声和延迟评价，再冻结硬件规格。

同一−45°目标试听：[512点](../../artifacts/runs/speech_20260920T061003_852487Z_decbe2d9/fixed_constraint_512_target_0.wav)、[1024点](../../artifacts/runs/speech_20260920T060927_725157Z_8140a9be/fixed_constraint_1024_target_0.wav)、[2048点](../../artifacts/runs/speech_20260920T060945_744072Z_2d0c1b2c/fixed_constraint_2048_target_0.wav)。同一共享增益0.5，不单独归一化。
