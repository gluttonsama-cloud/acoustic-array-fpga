## 口径与结果

采用[ADR0008](../技术决策/活动段与场景统计口径.md)的项目能量门限：全段参考去直流，20ms帧/10ms移，门限为峰值帧RMS下40dB与1e−5取大者，后延50ms；尾帧按真实长度。每个目标只生成一份掩码，各算法和FFT共用。完整信号先滤波、按相同0.05秒裁剪，再选掩码样本计算SI-SDR；整段指标并列保存。活动不足50ms或无变化参考明确不可评价，未把它当作计划静音或算法成功。

这是离线参考能量检测，不是语义VAD或ITU-T P.56。参考[librosa能量门限说明](https://librosa.org/doc/0.10.2/_modules/librosa/effects.html)理解帧能量方法，未复制源码或采用其默认参数；核对[ITU-T P.56官方说明](https://www.itu.int/ITU-T/recommendations/rec.aspx?rec=11461)以区分标准活动电平与本项目定义（2026-09-21）。

仍使用已有三人、已知方向、理想远场低噪声输入，100 Hz约束下限与−10 dB WNG门槛。裁剪后三路活动比例96.16%/81.01%/100%。100%仅说明所有帧达到该能量门限，不说明说话人一直在发声。

| 固定约束FFT | 整段全带SI-SDRi dB | 活动段全带SI-SDRi dB | 活动段500～5000 Hz SI-SDRi dB |
|---|---|---|---|
| 512 | 12.836 / 4.305 / 8.193 | 13.033 / 4.406 / 8.193 | 32.213 / 25.791 / 28.879 |
| 1024 | 10.359 / 4.672 / 5.997 | 10.669 / 4.795 / 5.997 | 39.120 / 33.038 / 37.034 |

顺序为−45°/0°/+50°，DAS结果亦全部保存在指标文件。活动口径没有改变本例主要取舍：512两侧全带较好，1024带内较好。变化不能解释成算法提升，只是评价样本集合变化。原输入按整段RMS归一化，未重新生成活动RMS等功率S1场景，所以即使掩码实现完成也不等于正式S1。

## 场景统计与划分

每场三路最小值作为S1分数，失败记−∞且保留分母；有限分数≤0单独计数。使用经验逆CDF分位数及场景级固定seed bootstrap，避免无穷值插值变NaN。计划静音须由调用方明确声明，不能按算法失败自动排除。单场景bootstrap区间退化为一个点，只用于验证统计实现，不能作为可信泛化区间或达标证据；两个FFT结果来自同一场景，不能合并成两个独立样本。

划分登记采用统一dataset_id=openslr12-librispeech，按数据集内说话人身份和原文件SHA-256同时检查development/tuning/heldout交叉。不同编码或裁剪的文件仍需保留同一说话人身份；该检查不能自动识别同人不同ID或伪造元数据，登记方须维护规范身份。

[split_registry.json](../../data/manifests/split_registry.json)只有现有3位development说话人，heldout为0。已核验[OpenSLR12](https://www.openslr.org/12/)的CC BY 4.0及test-clean来源，但本轮未下载新语料、未生成保留集。下一步需在查看算法成绩前冻结说话人/原文件清单和场景组合，排除198/3436/5703等已用开发说话人；30个种子不能代替30个独立内容场景。
