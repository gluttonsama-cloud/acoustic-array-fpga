# G1方向与距离误差诊断

> 文档类别：实验与验证｜状态：20条件开发诊断完成，非B2验收。[返回文档索引](../文档索引.md)。

日期：2026-09-23；v0.3.10诊断扩展。设计预先记录于[ADR0015](../技术决策/房间几何误差对照.md)，未引入新算法或用结果择优加载。

## 结论

主MPDR对方向误差明显敏感。2米、相邻间隔30度、无混响时，三路最差目标的带内SI-SDR改善从18.084dB降为−2度时5.618dB、+2度时7.335dB，分别损失12.466/10.749dB。原准确几何下的高分不能作为自动定位后的预期效果。该条件下DAS分别为5.654/5.330dB，MPDR的优势在−2度时基本消失；固定约束带内仍为18.843/19.787dB，但其强混响失败已经记录，不能据无混响成绩将其选作通用方案。

距离误差在这一有界实验中影响较小，但仍可见：同一30度无混响条件，假设距离1.5/2.5米时主MPDR带内降为14.731/16.237dB。不是说距离估计可以省略，也不表示±0.5米是系统允许误差。

标称0.4秒混响下，±2度导致主MPDR带内额外下降约0.127～0.358dB，而零误差原本只有2.324/3.634dB；这是本例变化较小，不能用来证明算法已经稳健。全带改善始终单独列出，不能以带内下降幅度替代全带听感。

## 设置与证据

- 复用同一房间run、三段开发语音和噪声seed；真实距离2米、间隔15/30度、标称RT为0/0.4秒，共4物理条件。不是20组独立说话人。
- 5组假设几何：零误差、三方向共同−2/+2度、三距离共同−0.5/+0.5米；每组均对DAS、固定约束、MPDR加载0.1使用相同假设几何。没有误差组合、逐源独立误差或运动。
- 512点/256帧移；混合协方差使用前0～3秒的561个完整帧；权重冻结，评分3.65～9.35秒；直接MIC7参考为主，三路取最小改善，带内500～5000Hz。完整混响参考结果也归档。
- 60条方法结果均完成、无目标评分失败；负性能结果原样保留。此轮未改变弱源电平，不声称已完成弱声实验。
- [五组运行索引](../../artifacts/validation/g1-geometry-runs.json) · [完整结果与检查](../../artifacts/validation/g1-geometry-checks.json)。每个run保存配置、源码快照、协方差、权重及manifest/completion。
- 所有20条件协方差与原实验逐元素一致；输入SI-SDR与活动样本数一致；零误差12方法行的输出评分与父实验最大差0dB；16条件改变几何后的DAS/固定约束权重复算逐元素一致；276项归档输出哈希通过。

## 对硬件决策的影响与下一步

先补方向估计/稳健约束的证据，不能把准确几何下的MPDR作为已经可部署的默认算法。当前结果不证明阵列必须更换，也不支持仅升级FPGA解决方向失配。后续按既定范围完成弱源电平对照，再以相同房间和信号做候选阵型对照，避免无限调参拖延阵列决策。自动DOA、实录、定点、板端和真实弱声应用可靠性仍未验证。


兼容路径实际回放：针对−2°、2m/30°/无混响，用三种冻结权重分别重放，18条目标/频带评分与父run最大差3.2e-14dB；全部44项产物哈希通过。[回放配置](../../configs/experiments/g1_geometry_replay.json)与[回放目录](../../artifacts/runs/g1_components_20260923T140728_240086Z)可复核。

此错误方向回放中，MPDR三个目标带内直达投影增益为0.862/0.905/0.842，投影残差相对参考能量为−15.92/−13.13/−11.43dB，进一步表明方向失配会改变目标直达成分。该单条件诊断不作为普遍容差或听感结论。
