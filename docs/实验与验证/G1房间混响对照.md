# G1房间混响对照

> 文档类别：实验与验证｜状态：18条件已完成，开发诊断非B2验收。[返回文档索引](../文档索引.md)。

日期2026-09-23；v0.3.9；定义与来源见[ADR0012](../技术决策/房间反射模型与双参考评价.md)。

## 结论与决策

**目前固定几何约束不适合作为本项目室内默认方案。** 在准确直达方向和距离下，512点约束法的带内场景最差目标改善中位数从无混响24.985dB，降到标称0.2s的1.261dB、0.4s的−0.634dB；全带分别为2.952、−0.836、−2.436dB。相同输入DAS的混响带内中位数为3.571/3.314dB，更稳定但仍未达到正式B2目标。

这是同一组三段开发语音和一个房间的诊断，不能宣称所有室内环境都不可行，也不能据此判定一定要更换阵列。已有明确的算法路线风险，先做稳健/协方差自适应波束对照；阵型和孔径保持可调整，FPGA升级暂缺依据。

每档混响有288条RIR（6条件×3源×16麦）。T30是−5到−35dB拟合后外推的60dB时间，不是直接测到60dB的时刻；也不是现实房间测量。

| 标称RT | 宽带T30 最小/中位/最大 | 带内T30 最小/中位/最大 |
|---:|---:|---:|
| 0.2s | 0.172 / 0.179 / 0.184s | 0.152 / 0.169 / 0.179s |
| 0.4s | 0.474 / 0.493 / 0.503s | 0.387 / 0.416 / 0.434s |

标称值与拟合值存在偏差，原样记录，不将0.4s配置描述成精确0.4s的声场。T20、各通道R²、尾能量及完整拟合结果在room_diagnostics.json；576条RIR的宽带和带内摘要已用当前代码逐项复算一致。墙面频率无关、无家具/散射/遮挡/空气吸收，不能模拟全部实际室内效应。

## 双参考的含义

完整混响目标MIC7参考结果也保存在metrics.json，并汇总于验证JSON。它会惩罚波束改变目标自身反射形态；不能把其低分简单等同于物理干扰泄漏。直接参考则将目标自身混响计入失真，两套参考均不替代独立分量SIR或听感。

共享定标重构另对原近场六条件的掩码/增益/时延逐元素回归一致；仍无真实采集、自动DOA、弱源电平差、动态源、定点或板端成绩。

## 下一步与硬件判据

1. 以本轮同输入DAS为必须战胜的基线，增加一种带加载和可观察回退的协方差自适应方案。干净源/真实RIR不能用于可部署分支；如使用理想协方差，只能另标上限诊断。
2. 对15°失败条件和30°中间条件补独立分量重放，区分目标自身失真、残余反射干扰和WNG噪声放大，再比较稳健约束，避免无界调参。
3. 若准确几何、自适应方案仍不足，在同输入/相同算法下比较可调整孔径或二维阵型。阵列几何问题与FPGA资源问题分开判定，不能通过更大FPGA修复空间可辨识性。
4. 同步争取单源/三源同步16通道实录，核验通道顺序、时延和底噪；无实录和综合结果前，不冻结室内性能或板端资源承诺。

完整G1还需弱源SIR=0/−5/−10dB等代表条件；本轮完成18条件房间网格，不是G1全部工作或正式B2通过。
