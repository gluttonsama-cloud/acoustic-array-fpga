# M2 每源方向误差与通道失配开发报告

> 文档类别：实验与验证｜状态：历史阶段记录；不代表当前项目状态。[返回文档索引](../文档索引.md)。

日期：2026-09-21；版本v0.3.2。新增静态通道误差注入和失配实验入口，默认波束参数不变。6个条件×2种FFT×2种方法×3路目标=72条混合评价，另有36条固定约束分量诊断；仍只有同一组三段开发语音，不是正式B1/B2或统计稳健性验收。

## 结论

本例中固定约束在全部六条件下仍优于DAS，但1024点在理想条件下的带内优势随失配明显缩小。不能仅凭理想样例选择最长FFT。512点保留更好的两侧目标全带分离，1024点通常具有更好的两侧目标保真度和中间一路成绩，继续保留两者。

## 场景与指标

- 父输入为已许可的三人10秒语音，真方向−45°/0°/+50°；100～5000 Hz约束、WNG门槛−10 dB、噪声RMS0.002、MIC7参考与原评价裁剪不变。
- 两种方向失配分别令假定方向为−46°/0°/+51°和−50°/+2°/+55°。这是每源分别指定的错误，不是统一偏移，也不是随机独立误差样本或自动DOA输出。
- 通道增益/延迟使用固定seed=20260921抽样的一组向量，范围±1 dB/±0.5 sample；每个数值写在配置中，MIC7固定0作为校准锚点。同一向量用于单因素和组合条件。
- 同一通道传递同时作用于源分量与前置噪声；不包含采样率漂移、时变抖动、丢样、后级噪声、混响或真实设备测量。
- 每个条件先变换一次输入，再交给512/1024与DAS/固定约束。评价使用实际源分量参考；两种方法均不知道通道误差真值，没有偷偷校正。整段评价，无正式活动掩码。

## 组合失配下的对照

| 方法 | 全带SI-SDRi，−45° / 0° / +50° dB |
|---|---|
| DAS 512 | 4.789 / 2.351 / 2.729 |
| 固定约束512 | 12.011 / 4.112 / 7.596 |
| DAS 1024 | 4.804 / 2.351 / 2.737 |
| 固定约束1024 | 9.905 / 4.450 / 5.589 |

固定约束两侧目标单独输出SI-SDR分别为512点20.51/20.03 dB、1024点24.94/24.40 dB。分离与目标保真度仍存在取舍。中间目标在理想正前方时仅有舍入误差，加入组合失配后目标单独输出SI-SDR约31.95/30.28 dB；这说明理想几何下的超高值不代表真实设备保真度。

1024点最差目标带内改善从理想33.04 dB降至组合21.96 dB，下降约11.08 dB；512点对应25.89至21.50 dB，下降约4.38 dB。两者组合条件最终成绩接近，不能把“下降更多”单独解读为1024最终效果更差。

## 实现与复现

simulation/mismatch.py提供二维PCM及三维源分量的同通道增益/时延变换，复用已有离线窗化sinc。pipelines/mismatch_experiment.py负责父输入校验、注入、波束/分量重放和归档。开发注入限制±20 dB/±4 sample；本实验使用范围更小。入口拒绝空/维度不符/非有限父数据、非静音要求不满足和参考锚点改变，验证发生在创建结果目录前。正延迟表示更晚到达，零误差保持输入逐位一致。

```powershell
.venv/Scripts/python.exe -m acoustic_array.pipelines.mismatch_experiment --config configs/experiments/m2_mismatch_development.json
```

依赖配置指定的父run（可按此前低频报告重建并更新路径）。结果保存12个输出NPZ（两种方法共24组输出）、12套权重与诊断、配置、指标、父manifest与源码/产物哈希；注入输入由父输入和显式误差向量重建，不重复保存巨大录音。原语音及派生数据遵循父run的CC BY 4.0归属与修改说明。

## 验证与限制

121项pytest通过，Ruff、pip check、editable安装与wheel构建通过。新增整数脉冲、分数时延解析正弦、分量线性叠加、输入拒绝与端到端失配重放测试。独立Python审查发现父维度校验、参考名硬编码和静音提前拒绝问题，已修正并复核；审查代理复跑相关13项测试和Ruff通过。

12组固定约束分量重放最大相对L2误差3.961e−16；输出峰值最大0.46732，未发现非有限指标或运行失败。理想条件512/1024输出与此前已归档结果逐元素相等，父manifest/源码/产物哈希通过。

目前只覆盖一组误差向量和三段语音。没有近角声源、不同房间/设备、时变误差或弱声功率比例扫描，因此不能声称“抗±1 dB/±0.5 sample误差已全面达标”。下一步优先扩大独立语料、正式活动段口径与场景统计，再安排近场/混响。默认参数不变；硬件校准和板端验收仍待实物信息。
