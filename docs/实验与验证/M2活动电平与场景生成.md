## 数值定义与验证

预处理语音先独立传播至各麦克风，从MIC7参考生成活动掩码，扣除两端2400样本裁剪后冻结。逐源增益令此掩码上的参考RMS均为0.04，评价复用冻结掩码。噪声各通道独立生成，再用一个全局增益令参考麦的裁剪整段噪声RMS为0.004；不是逐目标单独缩放噪声。

实测三源活动RMS均为0.040000，参考噪声RMS为0.004000；三个目标各自活动期间的SNR为20.0012、19.9953、20.0000 dB。不同活动时间使实际SNR略有差异，按原值报告。详细定义见[ADR0009](../技术决策/活动电平与场景定标.md)。

## 开发结果

同一10秒场景，方向−45°/0°/+50°，约束100～5000 Hz，WNG下限−10 dB。表中为活动段SI-SDR改善量，依次对应三个目标。

| FFT | 全带SI-SDRi dB | 500～5000 Hz SI-SDRi dB |
|---|---|---|
| 512 | 13.263 / 4.489 / 7.991 | 31.281 / 25.591 / 27.623 |
| 1024 | 11.083 / 4.884 / 5.873 | 36.047 / 31.990 / 33.336 |

DAS与整段结果同样保留在指标文件。这轮改变了源电平归一化与噪声电平，不能将分数相对旧run的变化称为算法升级收益。仍保留512/1024取舍，不据单个开发场景冻结参数。

首次尝试写完整16通道输入时发生磁盘空间不足，未生成有效结果。仅删除了本轮不完整的input.npz，留下[失败记录](../../artifacts/runs/active_scene_20260921T155441_179214Z/FAILED.md)，历史实验未删除。

新归档保存预处理sources、冻结mask、source_gains、完整配置/seed、权重、指标及源码/依赖哈希。通过build_active_scene可以重建全部源分量、噪声和混合，不再重复保存大体积16通道输入与多路浮点输出。本轮最终归档约11.37MB；已有源码/产物哈希、mask和gain逐元素重建核验。今后扩展语料仍需充足存储，紧凑归档不代表磁盘容量问题已彻底解决。
