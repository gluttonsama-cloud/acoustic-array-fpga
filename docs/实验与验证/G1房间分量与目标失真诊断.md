# G1房间分量与目标失真诊断

> 文档类别：实验与验证｜状态：开发诊断完成，后续独立审查已通过，非验收。[返回文档索引](../文档索引.md)。

2026-09-23；基于v0.3.10的离线诊断增量，冻结算法权重不变。定义见[ADR0014](../技术决策/冻结权重的房间分量诊断.md)。

## 发现与解释

在有目的选择的5个强混响条件中，MPDR直接目标投影增益范围0.9639～1.0032，最差直接分量投影残差/参考能量为−24.71dB；未观察到直接目标被大幅整体消除。这里不能扩大解释为目标语音全部无损。

**主要剩余困难是目标自身反射和其他说话人残留。** 主MPDR全带反射/直接功率比中位7.72dB，目标完整分量相对其他源的物理SIR中位−0.85dB；反射比直接更强，其他源总能量也仍可超过目标。因此上一轮直达参考改善与混响参考退化不矛盾：算法改变了目标自身反射形态，但并未充分分离全部声学成分。

这支持继续研究混响稳健性与目标声学传递建模，不支持仅凭当前结果就增加FPGA。阵列几何是否足够仍需合理算法对照和实录；孔径加大也不能被当作混响万能解法。
