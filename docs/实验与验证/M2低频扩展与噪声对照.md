# M2 低频扩展与噪声压力开发实验

> 文档类别：实验与验证｜状态：历史阶段记录；不代表当前项目状态。[返回文档索引](../文档索引.md)。

日期：2026-09-20；算法版本v0.3.0保持不变。本轮新增6份实验配置及结果，没有修改核心算法，也没有新增独立说话人。不是B1/B2正式验收。

## 结论

在同一三人语音开发样例中，降低约束频带下限能改善全带分离；100 Hz配置、WNG下限−10 dB的三个目标全带SI-SDRi为12.84/4.30/8.19 dB，原500 Hz基线为4.96/2.62/2.90 dB。代价是部分低频权重放大独立麦噪声。保留100 Hz方案作为研究候选，暂不替换默认500 Hz配置。

## 公平比较与边界

- 复用同三段许可明确的开发语音、10秒、−45°/0°/+50°、512点FFT、48 kHz、相同种子与音量。完整许可和预处理见[M2开发报告](M2真实语音开发基线.md)。
- 4组低噪声配置的input.npz哈希完全相同；2组高噪声配置之间也完全相同。比较组仅改变约束下限和WNG保护门槛。
- 低噪声RMS=0.002，方向共同偏差−5/0/+5°；高噪声RMS=0.02，仅0°偏差。不是独立DOA误差扫描。
- 评价仍固定500～5000 Hz和全带；相同参考MIC7、相同滤波、裁剪和整段评价，无对齐搜索、正式活动掩码、混响或通道误差。
- FFT间隔93.75 Hz：配置100/250/500 Hz实际首个候选频点为187.5/281.25/562.5 Hz。低于首个频点仍用DAS；100 Hz配置不等于已经在100 Hz形成约束。

## 低噪声结果

三个目标顺序均为−45°、0°、+50°。表中前三列为无方向偏差结果；最差值覆盖本组3个共同偏差×3个目标，不能视作独立场景统计。

| 约束下限 / WNG门槛 | 全带SI-SDRi dB | 500～5000 Hz SI-SDRi dB | 偏差扫描最低全带SI-SDRi dB |
|---|---|---|---|
| 500 Hz / −10 dB | 4.963 / 2.620 / 2.895 | 21.047 / 18.764 / 19.174 | 2.442 |
| 250 Hz / −10 dB | 7.643 / 4.305 / 4.070 | 31.572 / 25.885 / 28.271 | 3.592 |
| 100 Hz / −10 dB | 12.836 / 4.305 / 8.193 | 32.260 / 25.885 / 28.879 | 4.096 |
| 100 Hz / 0 dB | 6.177 / 3.222 / 3.361 | 29.303 / 26.718 / 28.170 | 2.986 |

100 Hz/−10 dB配置每组方向有1个“频点×输出”回退：187.5 Hz的中间目标。100 Hz/0 dB每组有6个回退，187.5与281.25 Hz的三路均使用DAS。250及500 Hz配置未回退。回退后的约束残差可能接近0.94，这是公开记录的约束放弃，不是成功零陷，也不是隐藏的求解误差。

100 Hz/−10 dB配置扫描中的最低实际WNG约−7.96 dB；单位目标增益下，对该频点的空间独立等功率麦噪声，相对单麦噪声功率约放大6.26倍。WNG是逐频点性质，不能直接代替整段噪声SNR。

带内分数也随低于500 Hz的权重改变而明显变化。实际STFT子带和评价滤波器不是理想砖墙分频，不能把“带内分数变化”解释为只改变了500 Hz以上权重；后续需做频率分解和分量评价。

## 十倍噪声幅度压力

RMS从0.002升到0.02，即噪声功率增加20 dB。以下报告输出的绝对SI-SDR，避免因输入基线变差而误把SI-SDRi上升解释为输出音质变好。

| 配置 | 低噪声输出全带SI-SDR dB | 高噪声输出全带SI-SDR dB | 高噪声输出带内SI-SDR dB |
|---|---|---|---|
| 500 Hz / −10 dB | 1.965 / −0.284 / −0.126 | 1.862 / −0.347 / −0.190 | 11.571 / 14.633 / 17.634 |
| 100 Hz / −10 dB | 9.838 / 1.401 / 5.171 | 8.946 / 1.288 / 4.900 | 15.903 / 18.433 / 21.432 |

本例高噪声下扩频仍优于原基线，但第一路全带下降约0.89 dB，基线下降约0.10 dB；扩频收益和噪声敏感性同时存在。中间目标输出全带SI-SDR仍只有约1.3～1.4 dB，远不能称为三人干净分离。

## FPGA影响与下一步

固定512点下只改变预计算权重，流式FFT尺寸、帧移、权重存储维度及复数乘加次数不变；扩大约束频点增加离线/控制端求解数量。低频权重范数增大可能提高定点动态范围和位宽需求，尚未证明资源/量化成本不变。

下一步先加入分量SIR和频段诊断，定位中间目标低频残留，再验证独立方向/通道误差。正式保留集、活动掩码、混响、自动定位和FPGA实测仍待完成。决策依据与资料见[ADR0005](../技术决策/低频扩展开发对照.md)。
