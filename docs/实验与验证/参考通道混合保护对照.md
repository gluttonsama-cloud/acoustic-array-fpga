# 参考通道混合保护对照

状态：2026-09-25固定对照完成，保护关口未通过；独立代码审查待完成。[返回索引](../文档索引.md)。

## 目的与来源

验证固定保守混合能否减轻上一轮错误方向的目标损伤，同时留下有用的定向收益。

依据[Goessling等，Binaural LCMV Beamforming with Partial Noise Estimation](https://arxiv.org/pdf/1905.04050)，读取摘要、引言及混合策略相关段落；作者指出参考通道混合可控制降噪与空间线索的取舍，相干干扰的结果与位置有关。本轮只借鉴输出与参考信号混合，不实现双耳BLCMV、不复现论文实验、不声称论文证明了误定位保护。

## 固定方案

保留既有起音MPDR估计角和权重，输出 y_protected=0.5*y_mpdr+0.5*x_MIC7，三路采用相同比例，没有标签驱动的开关。0.5在新结果产生前固定，为中等保守的一档工程设定，不声称最优；禁止追加比例扫描。另报原MPDR和MIC7参考（参考自身改善0dB）控制。

复用最终W4音频run的浮点输出，校验其哈希及父链；从原房间run精确重建未量化混音/干净参考，仅混音MIC7和原输出进入处理函数，干净参考与活动掩码只评分。前三秒不提供新输出；后段同样本索引混合，不使用未来样本或真值方向/距离。端口与旧评分关联不变，保留全部12目标。3.65～9.35秒、双参考、全带/500～5000Hz、活动口径和共同试听增益沿用。

## 门槛与停止

1. 双参考/双频带所有目标必须有有限指标和有效活动。
2. 主直达参考：全部12目标在全带及带内的SI-SDR改善均不低于-1dB，避免以均值掩盖退化。
3. 为避免退回混音冒充有效分离，在原起音定位5°内的目标上，全带及带内的SI-SDR改善中位数均至少3dB。定位真值匹配只用于固定评价子集，不参与处理；全部目标仍完整公布。

三个条件同时通过只允许进入独立实录验证，不算正式产品验收。失败即停止固定参考混合路线，不扫比例、不按真值切换DAS或混音。

## 设计时已经知道的限制

混合引回所有干扰；正确导向下的理想目标增益可保留，但错误导向的目标响应仍可能与参考反相，不能提供所有目标的数学保护保证。明确反例：当原输出为参考的负值时，50%混合为零。因此本轮测的是有限开发场景的取舍，不能称安全保证或目标恢复。全静音也不能产生虚构目标。

软件实现每输出每样本两次乘法一次加法，无新增自适应状态，另需对齐的MIC7参考；固定0.5可映射移位加法，但尚未做定点舍入/饱和与板端延迟验证。现有三秒定位启动及MPDR成本仍存在。

## 实际结果与决定

固定50%混合缓解了严重损伤，但没有通过保护门槛；停止该比例路线，不继续扫描混合系数。

| 条件 | 三目标最差全带改善dB | 三目标最差带内改善dB |
|---|---:|---:|
| r2_gap15_rt0.4 | -0.996 | -2.208 |
| r2_gap45_rt0.4 | 3.331 | 4.299 |
| r3_gap15_rt0.4 | 1.172 | 1.426 |
| r3_gap45_rt0.4 | 2.160 | 3.152 |

最坏目标仍是2米/15°漏定位的左源：全带从原MPDR的-7.886改善到-0.996dB，带内从-4.647改善到-2.208dB。全带刚过-1dB底线，带内未过。10个已定位目标的改善中位数为全带3.301、带内4.224dB，效用门槛通过；整体仍失败。参考直接监听自身改善为0dB，不能称分离。

这不是完全无收益：有限混合确实减轻部分损伤，也保留了一些方向性；但不能把“缓解”写成“可靠保护”。相位抵消反例与本轮带内失败共同排除了直接将它作为默认安全模式的依据。
