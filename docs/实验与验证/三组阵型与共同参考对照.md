# 三组阵型与共同参考对照

> 文档类别：实验与验证｜状态：首轮阵型筛选完成，交错布局保留为实录候选，非硬件定型。[返回文档索引](../文档索引.md)。

## 硬件建议

**保留现有16麦线阵作为控制样机，优先准备前后交错布局的可调原型；暂不因本轮结果直接重制最终阵列板。** 当前证据不支持优先把孔径拉长到685.8mm，也不支持升级FPGA。

在同一强混响条件下，交错布局的主MPDR三路最差目标全带SI-SDR改善5.068dB，相比线阵1.507dB提高3.561dB；带内8.413dB，相比3.634dB提高4.779dB。无混响全带不退步，通过预设的“保留为后续实录候选”关口。扩孔径候选强混响全带仅提高0.530dB，未达到预设至少1dB，停止该布局追加参数扫描。

这是两个物理条件、同一房间、同一组三段开发语音的筛选，不是二维阵列普遍更好或可部署产品的证明。它给出值得进一步验证的硬件方向，不能替代多场景及实录。

设计/门槛见[ADR0017](../技术决策/有限阵型对照与共同参考.md)，[运行索引](../../artifacts/validation/w3-array-runs.json)及[完整核验](../../artifacts/validation/w3-array-checks.json)。三组配置在运行前生成，不按成绩修改布局。

16麦、质心、MIC7物理位置保持一致；世界坐标声源2米、−30/0/+30度，房间6×5×3米，标称RT0/.4秒。实际衰减口径沿用房间模型，不将标称RT等同精确实测T30。

共享输入直接校准到MIC7活动RMS，噪声同seed；各阵型参考麦RIR、直达RIR、活动掩码、源增益和世界声源坐标已逐元素比对相同。原阵列显式坐标生成的完整RIR也与原归档逐元素一致。所有方法比较同一3.65～9.35秒区间，MPDR前0～3秒用含目标混合信号校准，加载0.1，之后冻结权重。

原room流程另保存0.65～9.35秒DAS/固定约束诊断；本报告表格统一取后续MPDR流程重算的相同后段评分，不混用两个区间。

## 接口、验证与审查

新增ArrayConfig.positions_m和显式schema0.2；核心权重、近/远场独立传播及房间RIR均使用实际坐标。默认ULA/schema0.1保留原语义。源仍为水平前半平面，不因麦克风支持三维坐标就宣称支持三维定位。

248项测试通过；Ruff检查/格式通过。309输出哈希、270源码快照文件哈希通过；原阵列与历史评分最大差0dB；各阵型参考输入SI-SDR及活动样本数一致。完成3个房间run＋3个MPDR run，表格18条方法结果无评分失败。

GPT-6 Sol/medium独立审查发现显式schema可携带旧ULA公式的元数据歧义；已拒绝该字段并增加回归断言，定向复核关闭。修复只增加错误配置拒绝，本轮三份配置运行前已移除旧公式，不影响已归档数值。原始快照保留。

## 代价与下一步

麦数、FFT与输出数不变，应用固定权重时复乘加数量不因阵型改变；但安装、布线、通道校准和DOA字典需要按真实坐标更新。扩间距改变高频响应/歧义，不能把原线阵半波长公式直接套到非均匀/交错布局；本轮不是完整空间谱或前后消歧验证。

先只保留baseline与staggered，锁定坐标与加载，在2/3米×15/45度、标称0.4秒的四个未用于布局选择的条件上做一次确认；全部结果保留，不再调整交错深度。若优势不稳定，维持可调两方案并优先实录，不开展无界阵型搜索。确认后进入W4多源定位/关联/多路输出，原始PCM和板端资源证据按W5并行补齐。

当前向硬件队友可交付的结论是“建议预留60mm前后可调安装并保持原线阵对照”，不是“必须重画PCB”。还缺真实麦型号、同步/增益校准、实录、综合与定点结果。
