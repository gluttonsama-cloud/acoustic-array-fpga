# ADR0006：扩展FFT长度开发对照

> 文档类别：技术决策｜状态：技术决策记录；保留原ADR标识与适用范围。[返回文档索引](../文档索引.md)。

日期：2026-09-20；状态：允许实验，不冻结部署规格。

分量诊断发现低频串音和两侧目标保真度下降，因此比较512/1024/2048点FFT（帧移N/2），约束下限100 Hz、WNG门槛−10 dB；另以1024点、WNG门槛0 dB观察保护代价。四组主对照保留同一10秒开发语音、种子、噪声RMS0.002、裁剪0.05秒、500～5000 Hz评价带及共同方向偏差−5/0/+5°。另加1024/2048点两组噪声RMS0.02压力对照，仅0°方向偏差，WNG门槛−10 dB，其余条件相同。

2026-09-21整理结论：保留512与1024作为后续比较候选；2048仅作为研究对照，不据单组开发语音冻结部署规格。详见M2变换长度与延迟对照.md。

采用现有实现，不新增算法或外部依赖。每组保存混合评价，并对无方向偏差输出作同权重分量重放。报告频率间隔、实际首个候选约束频点、保护回退、目标保真度、SIR/SNR和全带SI-SDRi。

当前流式实现首个完整有效输出块需N个真实输入样本：512/1024/2048点分别约10.67/21.33/42.67 ms，仅为采样等待，不包含采集、计算、调度、输出缓冲。2048点仅此一项已接近50 ms端到端目标；不能以音频文件对齐或PC执行速度宣称低延迟达标。

FFT长度改变不只是频率分辨率变化，还改变子带近似与时域处理。相同100 Hz配置的首候选频点随网格变化，解释结果时不能只归因为更长窗。对独立语料、混响或自动DOA没有新增证明，不降低现有B1/B2门槛。
