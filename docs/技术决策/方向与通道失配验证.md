# ADR0007：每源方向误差与静态通道失配

> 文档类别：技术决策｜状态：技术决策记录；保留原ADR标识与适用范围。[返回文档索引](../文档索引.md)。

日期：2026-09-21；状态：开发验证。

复用已归档100 Hz约束开发场景，比较512/1024点、固定约束与DAS。新增理想、每源小/大方向偏差、增益单因素、残余时延单因素、组合误差六种条件。方向误差是预设的每源不同向量，并非自动定位结果或统计独立随机抽样。

增益和时延向量由seed=20260921各生成一次均匀抽样，范围±1 dB/±0.5 sample，四舍五入到6位并写入配置；MIC7强制为0，保持参考。物理通道传递为先延迟再乘增益，正延迟表示更晚到达；采用既有离线窗化sinc与零延拓。该传递同时作用于全部源分量和前置麦噪声，不模拟后级独立电子噪声、时变抖动、采样率漂移或丢样。

每种条件先注入一次，再共享给两个FFT和两种波束；算法只获得假定几何和有误差的方向，不获得通道真值校正。固定权重逐分量重放验证线性重建，报告全带/带内SI-SDRi、物理SIR/SNR、目标保真度、回退与峰值。保存原始run依赖、参数、权重、输出与哈希，可重建注入后输入，不重复存储整份输入。

仍仅同三段开发语音、同一个通道误差向量，不构成独立语料、统计稳健性或B1/B2验收。默认配置和性能目标不变。该开发入口要求参考非静音，静音专用测试不进入效果比较。
