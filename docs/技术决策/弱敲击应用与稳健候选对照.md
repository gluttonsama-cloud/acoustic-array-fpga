# 弱敲击应用与稳健候选对照

> 文档类别：技术决策｜ADR0016｜状态：运行前固定设计。[返回文档索引](../文档索引.md)。

## 待决问题与固定输入

W1/W2只回答：在已知目标大致方向的条件下，真实门敲击比定向语音干扰弱10dB时，采用有限邻近方向约束能否比单方向加载波束更好保护目标。它不是自动检出或实际救援试验。

选用ESC-50中door_wood_knock类别按文件名排序第一条1-101336-A-30.wav，固定commit及哈希，原作者Robinhood76，数据集Karol J. Piczak，CC BY-NC 3.0；仅非商业开发评估，不能默认进入商业交付。声音是门敲击，非被困者敲击实录；不将现有朗读语料称为呼救。来源清单见data/manifests/weak_knock.json。

父房间2m/30°、标称RT0/0.4s；目标放0°，干扰在−30°。5秒目标于第4秒出现，干扰使用已有父run中第一段10秒开发语音；全长10秒。标定采用目标参考活动段的完整混响目标/完整干扰功率比SIR=−10dB，固定目标RMS=.01，噪声在同掩码参考通道SNR=20dB。另做完全相同目标/噪声的干扰关闭对照，不能称作SIR=0。

全方法前0～3秒只用可观测混合输入校准，冻结后处理后段；这次目标尚未出现，因此背景训练对协方差方法有利，不代表持续目标存在时的混合MPDR。此前mpdr_weights求解器可以复用，但本轮方法标为loaded_single。干净分量仅用于离线标定与评分。

## 候选与取舍

DAS、单方向加载协方差波束、三点LCMV。对目标估计方向共同注入−2/0/+2度。三点LCMV在估计方向及其±2度使用单位复响应约束，加载0.1、频带100～5000Hz与WNG保护不按结果调整；报告Gram病态、回退及真实目标失真。只在三个离散方向约束，不声称整个扇区连续保证；消耗自由度、可能减弱干扰抑制。来源核验后记录于研究文档。

这是“真实方向落在约束点上”的设计内测试，预期有利于目标保护。若有收益，后续仅增加预先固定的中间角/范围外检验，不能把本轮结果当泛化验收。

## 指标和停止条件

主看全带/500～5000Hz目标对其他源SIR、噪声比、目标失真与直达参考SI-SDR改善；同时生成同组统一增益试听文件。敲击事件的漏检/虚警尚无检测器，不能凭音频增强结果宣称搜索成功。

每个RT×干扰开关×3方向误差×3方法，共36方法结果。试验前设定开发选型关口：强干扰±2度四条件中，候选带内物理SIR相对loaded_single的中位变化至少+1dB、任一条件不低于−1dB，且目标单独对照的直接参考SI-SDR不低于loaded_single超过1dB；另报告全带变化与回退。此门槛是筛选候选的开发规则，不是产品验收。若大量带内回退或无明确收益，记录候选不入选，不继续扫宽度/加载。本轮只能决定是否保留候选，硬件决策仍需代表性阵型与实录对照。


用户最新范围澄清：本对照服务通用多源空间分离/定向拾音的弱声增强演示，不增加救援事件识别或呼救语义任务。[候选来源与代价](../参考研究/算法论文与产品调研.md)已核验。
