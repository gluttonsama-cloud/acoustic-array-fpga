# ADR 0005：低频约束开发对照

> 文档类别：技术决策｜状态：技术决策记录；保留原ADR标识与适用范围。[返回文档索引](../文档索引.md)。

日期：2026-09-20；状态：实验批准，默认处理规格保持不变。

M2开发样例带内改善明显、全带改善有限。本轮复用现有固定几何约束求解器，不增加自适应算法，扫描约束下限500/250/100 Hz；100 Hz另设WNG下限0 dB，与原−10 dB对照。统一512点FFT、10秒素材、噪声/种子、三路方向及共同偏差−5/0/+5°，评价仍报告500～5000 Hz和全带，禁止改变评价带宽后直接横向比较。

频率间隔93.75 Hz，因此上述约束下限实际首个处理频点分别为562.5、281.25、187.5 Hz；不声称已经处理到100 Hz。DC及93.75 Hz仍使用DAS。保存每频点回退状态与WNG，关注最低全带改善、峰值和方向偏差下的退化。

参考MathWorks官方[麦克风阵列波束形成示例](https://www.mathworks.com/help/audio/ug/acoustic-beamforming-using-a-microphone-array.html)（2026-09-20核验）：方向误差会影响输出，稳健化方法需要比较。本项目当前采用固定约束及WNG回退，不把它描述为该示例中的自适应Frost或对角加载算法。对单位协方差仅乘以正标量不会改变精确约束的最小范数解，因此不机械加入所谓“对角加载”开关。

本轮仅同一开发混合的参数实验，不增加独立场景数，不代替B1、独立方向误差、通道误差或混响验收。实验结果决定下一步，不自动修改默认配置。
