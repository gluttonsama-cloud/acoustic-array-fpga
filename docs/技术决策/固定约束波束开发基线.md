# ADR 0004：固定约束波束与真实语音开发实验

> 文档类别：技术决策｜状态：技术决策记录；保留原ADR标识与适用范围。[返回文档索引](../文档索引.md)。

日期：2026-09-20；状态：v0.3.0开发基线，未完成M2正式验收。

## 决定

先实现每频点CᴴW=I的最小范数解，即单位协方差条件下的固定几何约束波束。采用SVD最小二乘，不通过显式矩阵求逆实现，也不称为已完成自适应LCMV。

约束带内检查秩、C的条件数和白噪声增益WNG；不合格频点/输出回退DAS并保留状态和实际残差。初始条件数上限1e4、WNG下限−10dB是可配置工程保护，不是已经证明最优的鲁棒参数。带外继续DAS，保留全带输出。

STFT重建处理抽取为StreamingBeamformer，DAS和约束方法共享完全相同的分帧/重建/评价流程，避免方法比较时暗中改变后处理。

## 语料和使用范围

引入librosa托管的三个LibriSpeech短片段，官方许可说明为CC BY 4.0，原文件哈希与官方registry一致。只下载三份总计约0.24MB的示例，不下载完整数据集；通过SoundFile解码与SciPy resample_poly重采样，不引入完整librosa依赖。

片段用于开发和听感检查，不能再作为独立保留集。每人取前10秒，去直流并按整段RMS归一化；该口径不同于正式S1的活动段RMS，必须单独标记。

## 实验

真实方向−45°/0°/+50°。对全部假定方向施加共同偏差0/±1/±2/±5°，比较256/512点和两种方法。共同偏差只是一个失配维度，不代表任意独立定位误差、跟踪错误或实际DOA系统已经稳定。

文件以偏差索引命名，精确浮点偏差写入NPZ/JSON，避免显示格式精度造成覆盖。频带无可用FFT bin时在创建run前拒绝。

## 下一步依据

若带内改善大而全带有限，应从真实目标频谱和带外策略分析，不通过只报带内指标掩盖问题。扩展低频约束前需要检查病态与噪声增益，并记录对原参数表处理范围的版本变化。

混响、独立通道误差、近角源、更多说话人和保留测试集尚未验证。只有完成原BENCHMARK_PROTOCOL规定的数据量与条件才能宣布B1达标。
