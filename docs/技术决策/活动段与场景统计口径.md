# ADR0008：参考活动段与场景统计口径

> 文档类别：技术决策｜状态：技术决策记录；保留原ADR标识与适用范围。[返回文档索引](../文档索引.md)。

日期：2026-09-21；状态：项目评价协议v0.2，先在开发数据验证，不重写历史结果。

定义本项目离线参考能量门限：参考信号全段去直流后，20ms矩形帧、10ms帧移，尾帧只用实际样本；帧RMS门限=max(1e−5,最大帧RMS×10^(−40/20))，大于等于门限为活动帧。将活动帧覆盖范围及后延50ms映射到原始样本。阈值/时长固定，不由各算法输出或VAD决定，不称为ITU-T P.56或语义语音检测。

先在完整MIC参考上生成掩码，再按既定裁剪选取评价样本；带内滤波在完整信号上先执行，再使用同一掩码。选中的样本按原顺序计算零均值SI-SDR；不进行时间拼接后的滤波、不重新对齐。活动少于50ms或参考无有效变化时标记N/A。整段指标继续并列保留，防止门限掩盖静音泄漏。

S1场景分数为三路有限SI-SDRi最小值；运行失败保留在分母，分数−∞并用JSON状态表达，有限分数≤0另计无改善。计划静音场景单独计数、不进效果分母。以场景为单位bootstrap，中位数和P10使用经验逆CDF（inverted_cdf），避免含−∞线性插值产生NaN；bootstrap的95%区间也使用相同分位数定义。明确小样本只作描述，不自动作B1达标判定。

数据划分检查按(dataset_id,speaker_id)与源文件SHA-256同时阻止development/tuning/heldout之间泄漏；不同裁剪或种子不能赋予同一源文件新的独立身份。划分校验不等于已有独立数据。现有三段LibriSpeech样例仍仅development。
