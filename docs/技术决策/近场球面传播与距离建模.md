# 近场球面传播与距离建模

> 文档类别：技术决策｜状态：采用用于开发诊断。[返回文档索引](../文档索引.md)。

ADR0011；日期：2026-09-22；版本：v0.3.8。

## 问题与选择

原S1使用平面波和准确方向，不能解释实际2～3m内的波前弯曲损失。先加入直达球面波，以同一近场输入对比平面权重和准确距离的匹配权重，再加入反射和自动定位。此阶段是G1的一部分，不是完整B2或真实房间验证。

源坐标以阵列中心为原点，方向延续正前方+y、正角向+x。每个源提供中心距离；麦克风路径长度为r_m。输入源定义为物理参考MIC7处的声压，传播为幅度r_ref/r_m、相对延迟(r_m-r_ref)/c。因此不含绝对传播时间，不测试随距离降低的声压、发射功率或空气吸收。活动RMS仍在MIC7统一为0.04。

在已有steering_vectors、das_weights、constrained_weights增加可选source_distances_m。省略时保持平面算法。匹配DAS权重使用a/(aᴴa)，约束波束仍解CᴴW=I，继续记录条件数、残差、WNG及回退；DC/Nyquist保留原实数端点策略，任意分数延迟在Nyquist处不是精确复响应。

独立标量传播实现位于simulation/near_field.py，使用时域窗化sinc分数延迟，避免直接用频域导向矢量生成场景掩盖符号错误。声源不能与麦克风重合。近场模块不依赖权重模块，也不引入房间仿真库。

## 来源与采用范围

访问日期2026-09-22。依据官方文档及作者项目公开实现说明，独立编写球面直达传播，没有复制第三方代码或新增依赖。

- [Pyroomacoustics波束形成文档](https://pyroomacoustics.readthedocs.io/en/pypi-release/pyroomacoustics.beamforming.html)：点源steering、attn、ff区分。只采用距离相位与幅度建模概念。
- [LCAV作者实现](https://github.com/LCAV/pyroomacoustics/blob/master/pyroomacoustics/beamforming.py)：点源1/(4πr)与传播相位，转换成MIC7相对声压后公共系数消除。坐标角度约定按本项目实现，不能直接照搬其角度参数。
- [MathWorks球面波阵列响应](https://www.mathworks.com/help/phased/ref/phased.sphericalwavefrontarrayresponse-system-object.html)：交叉核对球面阵列响应适用对象；未运行MATLAB交叉验证。

## 代价与边界

新增O(MK)距离计算以及O(FMK)导向矢量生成，仍在离线/控制端形成权重。约束求解保持逐频SVD，PC参考不代表已完成PS性能预算。PL频域复乘加的维度、权重存储、STFT状态和帧移不变，不因加入距离参数自动要求更大FPGA。

近场匹配依赖准确距离；这是oracle诊断分支，自动距离估计尚未实现。短FFT、空间孔径、相邻角度小、WNG回退和模型误差仍可能限制分离。定点尚未建模，距离和权重精度须后续做敏感性验证。不能以该对照直接冻结硬件或声称真实房间效果达标。

结果见[G1近场传播与距离建模对照](../实验与验证/G1近场传播与距离建模对照.md)。
