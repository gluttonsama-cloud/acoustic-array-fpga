# ADR 0001：独立项目和三层数值实现

> 文档类别：技术决策｜状态：技术决策记录；保留原ADR标识与适用范围。[返回文档索引](../文档索引.md)。

日期：2026-09-19；状态：接受作为初始架构。

## 背景

用户改换选题，要求代理承担算法实现并提高质量标准。已有工作区包含另一套设计，不能让旧参数或界面组织限制新算法工程。

## 决定

新建独立目录。研究浮点、可部署浮点、定点对照遵循同一数据语义，但数值实现可分离。模块按职责分层，核心算法不依赖 IO/GUI。先用纵向功能贯通，再根据实际替换需求提取接口。

## 备选与取舍

- 单一实验脚本：启动快，但难以回归、复用和硬件交接，拒绝作为最终结构。
- 先建通用插件框架：抽象复杂且需求未验证，暂不采用。
- 直接从RTL开始：难以区分算法缺陷和实现缺陷，先做软件参考与数值契约。

## 后果与复审触发

需要维护不同数值分支的一致性测试。增加第二种阵型、C/C++后端或新处理链时复审接口；不因一个新增算法就重构全部目录。
