# 混合协方差加载与分段校准

> 文档类别：技术决策｜状态：用于G1开发对照。[返回文档索引](../文档索引.md)。

ADR0013；2026-09-23；v0.3.10。

## 选择与术语

房间混响实验说明固定几何零陷会放大非模型方向的反射干扰。新增混合信号协方差最小功率无失真响应（MPDR）：只约束每个目标直接方向的单位响应，不给另外两个目标施加硬零陷。协方差包含目标本身，因此不称为已获得目标无关噪声协方差的MVDR，更不是已解决全部混响问题。

参考[官方MVDR权重说明](https://www.mathworks.com/help/phased/ref/mvdrweights.html)、[子带MVDR与对角加载](https://www.mathworks.com/help/phased/ref/phased.subbandmvdrbeamformer-system-object.html)、[常规/自适应波束与目标自抵消](https://www.mathworks.com/help/phased/ug/conventional-and-adaptive-beamformers.html)。访问日期2026-09-23，阅读官方说明/方程及风险段落，独立实现，不复制第三方代码、无新运行依赖、不声称原创或完整论文复现。

## 算法与保护

每频点R=平均xxᴴ，对角加载为λ·trace(R)/M·I；分别求解加载矩阵u=a，再令w=u/(aᴴu)。使用线性求解器而不是显式矩阵求逆。将R除以平均对角功率后求解等价系统，整体音量缩放不改变权重。验证有限值、Hermitian和PSD；近零功率、条件数或WNG触发明确DAS回退。带外使用相同近场DAS。

本轮λ=0.1作为主方法、1.0作为预先固定的敏感性对照；不按结果择优宣称验收。100～5000Hz处理，WNG下限−10dB、条件数上限1e6。每输出的constraint_residual表示|a_kᴴw_k−1|，不表示固定三约束方案的整个CᴴW−I零陷残差。condition_number指加载协方差条件数，两者与原固定约束诊断不能直接横比数值大小。

## 时间与数据边界

从已归档G1房间RIR和语音重建原18条件，不重生RIR、不使用S1保留集评分。父run先核验全部输出哈希，掩码/整源增益重建后必须逐元素一致。

每条件只用前3秒混合PCM估计R，既不用真实源分量，也不用活动真值选择协方差帧。使用完整且无零填充的STFT帧，至少M帧；512/256帧移在本轮取得561帧。第3秒之后才使用冻结权重产生输出，首3秒不提供增强结果；再用0.65秒保护区，评分3.65～9.35秒的直接参考活动段。权重已确定后，未来输入不会改变已产生输出。

活动掩码与干净直接分量仍仅用于场景定标和离线评价；准确直接方向/距离仍是oracle几何。DAS和原固定约束也在相同区间重新处理和评分，因此不得与上一轮0.65～9.35秒汇总直接相减作为算法增益。

双参考、先滤波后掩码、三路最差目标SI-SDR改善和失败保留继承房间协议。离线带通评分用双向滤波，不是在线算法的一部分。

## 部署代价与限制

本次是“前段校准、后段冻结”的可运行基线，不是持续跟踪更新。运行中改变方向/距离、说话人或噪声时，旧协方差和权重可能过时。尚无权重平滑、更新节奏、启动增强体验、定点或硬件时序实现。

512点257频点×16×16协方差若全矩阵complex128保存约1,052,672字节（约1.00MiB），complex64约0.50MiB；可仅保存处理频点及Hermitian半矩阵但尚未实现。协方差更新O(FM²)，每次求解O(FM³+FM²K)。本轮只是一次3秒校准后求解，不把PC计算时间当PS/PL预算。冻结后的3波束频域复乘加与原维度相同；实际在线更新成本需独立测量。

若该基线能稳定超过DAS，后续再研究持续因果更新、保护与几何误差；若仍不足，做分量重放/理想统计上限诊断，再比较阵列几何。原B2门槛不下降，不能由一个开发组宣称通过。结果见[G1混合协方差波束对照](../实验与验证/G1混合协方差波束对照.md)。
