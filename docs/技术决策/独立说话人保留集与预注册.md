# ADR0010：不复用说话人的S1保留集与预注册

> 文档类别：技术决策｜状态：技术决策记录；保留原ADR标识与适用范围。[返回文档索引](../文档索引.md)。

日期：2026-09-22；状态：采纳，尚未评分。

上一版30个场景复用30位说话人，不能满足30个独立场景的证据要求。扩充test-clean/dev-clean/dev-other各30位不同说话人、每人一段，按各子集数字顺序分为10个三人场景。跨子集和开发/调参集均检查说话人及文件哈希。固定条件选择在新数据获取前完成，不根据声学算法成绩挑片段。

这满足本轮30个场景的说话人不复用要求，但仍是单一英语朗读语料的条件评价。较难dev-other录音分组报告，不将其称为源本身完全无噪声。参考真值是所选源录音的模拟阵列传播贡献。

评价前固定512点/100～5000Hz约束主方法和1024点次要方法，DAS/单麦对照；主评价频带仍500～5000Hz，原B1门槛不变。三个子集各10场，分层bootstrap保留该构成。代码实现与正式评分在此决定之后，不将预注册文件误报为运行结果。

来源、证据、缓存策略及待完成项见[S1不复用语料报告](../实验与验证/S1独立说话人语料与评价预注册.md)。
