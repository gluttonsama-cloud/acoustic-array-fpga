# ADR0009：活动RMS场景生成与噪声定标

> 文档类别：技术决策｜状态：技术决策记录；保留原ADR标识与适用范围。[返回文档索引](../文档索引.md)。

日期：2026-09-21；状态：开发实现，协议v0.3补充。

源文件按既有加载器重采样、裁剪、去直流，加载器的整段RMS仅是预处理。对未加最终增益的独立传播MIC参考按ADR0008生成活动mask，再去除两端固定裁剪，冻结此mask。以该mask的均方计算每源增益，使MIC参考活动RMS为0.04；后续评价直接使用冻结mask，不因最终音量改变绝对门限而重算。保存mask和增益可重现，不能用算法输出选取活动段。

各通道独立标准高斯噪声使用同一个全局缩放因子，使参考MIC的裁剪整段噪声RMS恰为0.04/10^(20/20)=0.004。其他通道和各目标活动期间的实测噪声会有有限样本差异；报告每路实际活动SNR，不分别缩放同一噪声使其伪装成三路同时精确20dB。此处明确S1的20dB为活动目标电平相对参考整段噪声电平的设定值。

远场传播、算法与独立语料要求不变。仅升级场景生成，不将当前三段开发语音当作正式保留集；旧run保留旧音量与噪声设置，不与新run直接计算算法增益。
