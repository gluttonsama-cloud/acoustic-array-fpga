# 房间反射模型与双参考评价

## 采用已有实现

选择Habets的官方Python移植版rir-generator 0.3.0，MIT许可，通过可选room依赖安装；Windows CPython3.12官方wheel已经可用，不复制源码或自行重写镜像声源算法。目的只是在离线侧产生矩形房间脉冲响应（RIR），不进入可部署流式链。

## 几何与信号契约

固定6×5×3m房间，阵列中心(3,1.5,1.5)m、x向16麦；声源与阵列等高，中心距离2/3m，三源−间隔/0/+间隔，间隔15/30/45°。各点必须严格位于房间内部。

每源所有麦的RIR共同乘4πr_ref，使直达声MIC7幅度为1，但保留绝对到达时间。零混响控制组也走同一个生成器的零阶直接路径，避免更换分数延迟滤波器造成比较偏差。与上一轮相对延迟G1使用不同插值核、绝对时间及裁剪，因此使用本轮零混响作为配对对照，不直接逐数替代上一轮成绩。

直达分量决定每源活动掩码和0.04活动RMS增益；整个含反射分量使用同一增益，保留直达/混响比。MIC7裁剪后噪声RMS固定0.004。noise_snr_db指直达目标相对传感器白噪声，不含反射和其他声源，不是房间总SNR。

输入时长10s，离线零状态卷积保留前10s，首尾各裁0.65s，所有条件一致。没有评价音频末尾混响尾音；RIR本身完整保存、单独评价衰减。最大RIR 0.65s，正标称RT按min(上限,1.5×RT+0.05)保存，即本配置0.2→0.35s、0.4→0.65s。无反射控制RIR为0.65s的零填充直接路径。

权重只看到准确直达方向/距离，不能读取RIR、分量或活动掩码。近场DAS与固定约束、512/1024点共四种方法，设计频带100～5000Hz、WNG−10dB不按房间成绩调参。

## 双参考和衰减口径

同一输出同时报告：

- 直达参考SI-SDR及改善：把目标自身反射也计入偏离干净直接信号的程度。
- MIC7完整混响目标参考SI-SDR及改善：考察输出与目标在参考麦处完整声学形态的一致程度。它会惩罚目标自身混响被改变，并非纯粹的物理分量SIR，不能用来单独判定干扰抑制能力。

两种参考均报全带与500～5000Hz，滤波先于活动掩码；零均值投影，不做额外对齐/输出归一化。场景分数取三路最小值，失败目标显式保留。六条件重复同一组三段开发语音，不推断独立说话人总体效果，不作B2验收。

对每条模拟RIR做Schroeder逆向能量积分，拟合−5～−25/−35dB并外推到60dB，分别记T20/T30，报告R²、拟合时间及最后10%能量。这是无噪声仿真描述性检查，不是认证的建筑声学测量。标称RT来自逆Sabine，必须与实际拟合结果分开。墙面为频率无关吸收，不含家具、扩散、空气吸收或遮挡；线阵同高对称场景亦不等于全部真实房间。

## 工程影响与下一步

RIR生成/卷积只在离线端使用；最多两个原生计算线程，源分量通过保存输入、RIR、增益和seed可重建。原始run保存启动时源码快照、输入/输出SHA和依赖版本，长实验期间的维护不能改写运行依据。

波束PL链维度没有改变。本实验不增加实际FPGA资源或延迟声明；当前无定点仿真或板端证据。混响失败先比较稳健约束及协方差自适应基线，再评估阵列孔径/形状；不能从固定约束失败直接推断必须更大FPGA。报告见[G1房间混响对照](../实验与验证/G1房间混响对照.md)。

检查点记录run_status与expected_cases/completed_cases；中断时保留in_progress。完整性须同时核对最终manifest与预期条件数，不能仅凭已有metrics.json判定整轮完成。
