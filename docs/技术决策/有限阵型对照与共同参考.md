# 有限阵型对照与共同参考

> 文档类别：技术决策｜ADR0017｜状态：运行前固定设计。[返回文档索引](../文档索引.md)。

## 待决问题

保持16通道时，增加横向孔径或增加少量前后空间分布是否值得改变硬件原型。此处为两个工程候选，并非最优阵列设计或文献性能承诺；不开展无界布局搜索。

候选固定为三组：原线阵显式坐标；外侧14麦横向坐标扩大1.5倍、中央MIC7/8不动；原横向坐标不动、前后交错±30mm且中央MIC7/8保持y=0。全部z=0、质心0、MIC7物理位置相同、麦数16。第一改型最大横向长度685.8mm，第二布局最大前后跨度60mm。中央不动是为了共用真实参考麦位置，扩孔径候选因此是非均匀阵列，不能叫作1.5倍等间距线阵。

全部用实际坐标计算，不用名义spacing推断几何。扩大间距存在高频歧义代价，二维交错可能改变不同方向响应；不能只展示低频收益或由二维坐标推断已能360度/3D定位。当前方向接口仍为前半平面水平角。

## 公平性与范围

同一6×5×3米房间、中心(3,1.5,1.5)、三源2米/−30,0,+30度、同开发语料、同噪声seed与同参考麦。标称RT0/.4s，512点、原固定约束及DAS先归档，再在同评分区间运行loaded MPDR .1。真实源世界坐标和参考位置相同，因此参考输入/定标应一致；若不一致先解释，不能直接报算法收益。

以三路最差直达参考SI-SDR改善为条件分数，报告500～5000Hz与全带；增加物理尺寸、实际最邻近/最远距离和计算量边界。只有两个物理条件，不代表真实总体或独立验收；本轮不是W1敲击复跑，而是回到多声源核心评估几何。

预设判据：若改型在强混响全带提升至少1dB、带内不退步且无混响全带不下降超过1dB，则保留为后续实录候选，仍不得直接定板；否则没有足够证据改变现有布局，保留可调样机并说明限制。不按成绩重新改布局。

## 接口与退出

ArrayConfig可选positions_m，schema0.2明确坐标行对应通道，质心为原点、参考麦为实物通道；schema0.1原ULA语义不变。仿真独立计算路径，避免只改权重而未改传播；先验证显式原ULA与旧默认传播/权重一致。

当前先完成接口与原阵列回归，再执行三组固定配置。若可选依赖/磁盘/审查服务受限，记录具体未完成项，不将接口实现称作硬件结论。每个run独立归档，S1不参与调参。

执行结论见[三组阵型报告](../实验与验证/三组阵型与共同参考对照.md)：交错布局通过首轮保留门槛，扩孔径未通过；不改变原门槛，不重新搜索布局。


## 四条件一次确认预设 — 2026-09-24

只比较锁定的baseline和staggered；2/3米×15/45度、标称RT0.4秒共四条件，不含用于首轮选择的2米/30度。原线阵复用原G1房间归档的同条件RIR，上一轮已证明显式坐标基线与原ULA逐元素一致；双方仍用同一MPDR后段评分流程，加载0.1、坐标与种子不改。原G1条件已用于基线诊断，因此本轮是未参与布局选择的条件确认，不宣称全新独立保留集。

主判据在运行前固定：交错布局相对线阵的四条件全带min3 SI-SDR改善变化中位≥1dB、最差≥−1dB，且带内变化中位≥0dB，才保持“优先可调实录候选”建议。否则降级为证据不足、两方案均保留可调；不得按成绩改变布局或指标。所有条件原样报告，即便只在部分条件有效也不能隐藏失败。

完成本轮即结束布局参数扫描；无论结果如何转W4自动定位/多路输出，并列出对硬件建议的限制。实录与资源报告仍是最终定型门槛。
