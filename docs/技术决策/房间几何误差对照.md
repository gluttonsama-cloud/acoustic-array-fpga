# 房间几何误差对照

> 文档类别：技术决策｜ADR0015｜状态：开发实验已执行。[返回文档索引](../文档索引.md)。

日期：2026-09-23。已有混合协方差加载实现与研究来源沿用[ADR0013](混合协方差加载与分段校准.md)，本轮不引入新算法。

## 问题与预设

准确几何是目前MPDR实验的理想条件；先单独改变波束使用的方向/距离，检验这一优势对几何误差是否敏感。真实输入、RIR、噪声、说话人、电平、校准区间和评分区间全部保持父实验定义。

预先选择2米、相邻间隔15/30度、标称RT为0/0.4秒，共4条件。每条件运行共同方向偏差−2/0/+2度，或共同距离偏差−0.5/+0.5米；不混合两类误差，共5组设置、20条件、60方法结果。选择包含直达控制和强混响失效场景，不代表随机总体，不能替代正式B2。±2度和±0.5米是敏感性探针，不是定位器已达到的误差。

DAS、固定约束、MPDR加载0.1均使用同一假设几何。固定约束的频带、WNG、条件数阈值继承原房间配置；MPDR继承原加载及保护阈值。共同方向偏差不改变三源相对间隔；该实验不覆盖逐源独立误差或阵列通道位置误差。

## 评价与退出

校准0～3秒，冻结权重处理后段，评分3.65～9.35秒；直达MIC7参考为主，完整混响参考作为旁证。每个条件取三目标SI-SDR改善最小值，分别报告500～5000Hz和全带，并相对各方法零偏差结果计算损失。零偏差重跑必须与原MPDR父实验一致。

先检验共用协方差一致、全方法几何一致、输入评分指标不变和归档完整，再讨论结果。不能按该四条件表现修改加载后声称原模型稳健。方向误差敏感则优先稳健约束/方向估计；零偏差本身不足仍需后续弱源和阵型对照，不能直接推断要换FPGA。

弱源电平对照留作独立增量，避免同时改变多个因素而混淆原因。独立审查状态和最终运行证据写入实验报告。

执行结果：见[G1方向与距离误差诊断](../实验与验证/G1方向与距离误差诊断.md)。20条件/60方法结果完成；方向失配敏感性明确，未调参改写本预设。
