# 冻结权重的房间分量诊断

> 文档类别：技术决策｜状态：用于开发失败诊断。[返回文档索引](../文档索引.md)。

ADR0014；2026-09-23；基于v0.3.10增加诊断，原算法权重不变。

## 为什么增加分量重放

上一轮MPDR直接参考评分提高，而完整混响参考评分下降；仅靠SI-SDR无法区分干扰抑制和目标自身反射形态变化。本轮不新增波束算法、不重估权重，复用原run的DAS、固定约束、主MPDR权重，把各物理源和噪声分别通过同一流式处理链。

已有方法/实现依据：[分量重放与低频残留](../实验与验证/M2分量重放与低频残留.md)、[房间反射模型与双参考评价](房间反射模型与双参考评价.md)、[混合协方差加载与分段校准](混合协方差加载与分段校准.md)。本轮是现有线性系统叠加与能量分析的复用，没有新增论文算法或第三方依赖。

## 定义与限制

目标完整分量包括自身直达与反射；其他说话人的完整分量先按波形相加后取能量。物理SIR=目标完整分量能量/其他源总波形能量；它可以在目标自身混响很强时仍较高，因此不代表去混响或清晰度。

分别重放直接分量与完整分量，反射输出=完整−直接。报告直接功率、反射功率、2mean(直接×反射)交叉项，并核验三者之和等于完整目标功率。直达和反射来自同一源，不能假定不相关、不能直接把能量相加。

直接投影增益相对于MIC7直接参考做零均值最小二乘标量投影；误差能量比报告投影后残差/参考能量，不做时移搜索或逐频增益拟合。接近单位增益及低残差只说明直接分量被保留，不代表反射目标或整个语音无失真。

所有分量沿用前3秒校准已冻结的权重，处理3秒之后相同尾段，在3.65～9.35秒原目标活动mask评分。500～5000Hz先对整段输出滤波再取mask，全带并列。真值仅进入诊断，绝不用于重新设计权重。

6条件按失败与控制挑选：2m/15°无反射控制，加2/3m、15/30°、0.4s四个困难条件，以及3m/45°、0.4s对照。这是有目的的失败分析，不能当随机总体或重新定义验收集。主方法0.1固定，不纳入1.0择优。

归档以父run哈希链、源码快照、指标和completion完成凭据追溯。完整输出与各源输出+噪声逐样本比对线性重建；并与父run逐目标SI-SDR复算对照。冻结权重不会引入新的协方差或硬件资源，重放全部是离线诊断。

结果见[G1房间分量与目标失真诊断](../实验与验证/G1房间分量与目标失真诊断.md)。
