# ADR 0002：分层算法路线与高标准证据

> 文档类别：技术决策｜状态：技术决策记录；保留原ADR标识与适用范围。[返回文档索引](../文档索引.md)。

日期：2026-09-19；状态：接受为研究顺序，具体优胜算法待基准决定。

## 决定

先验证已知方向的DAS与固定约束波束，再引入自动定位、跟踪与稳健处理。MVDR/LCMV、SRP-PHAT以及离线盲分离用相同测试条件比较，避免仅凭知名度选型。产品用于需求/体验对标，不推断专有内部算法。

## 理由

把定位误差、模型误差、数值误差、跟踪错误分开可提高定位效率。已知方向基准是oracle上限，不能标为自动系统成绩。16麦并不保证能在所有频率稳定实现任意深零陷。

## 高标准与修订

基准协议的性能目标需用保留测试集达成；未达目标须明确原因。阈值或范围改变追加新ADR并保留原报告，不能通过删除失败场景或统一更换评价带宽“达标”。

## 后果

初期工作包括独立评价与数据追溯，而非只追求演示音频。深度学习暂不作为主线，若经典方法无法满足经验证的场景需求，可根据增益、数据、计算和硬件代价重新决策。
