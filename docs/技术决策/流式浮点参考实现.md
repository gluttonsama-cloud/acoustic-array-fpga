# ADR 0003：M1 因果分帧、数值参考和实验边界

> 文档类别：技术决策｜状态：技术决策记录；保留原ADR标识与适用范围。[返回文档索引](../文档索引.md)。

日期：2026-09-19；状态：已用于v0.2.0基础链路。

## 选择

- 以NumPy FFT、SciPy窗函数/滤波/卷积为基础，自己组织少量显式流式状态；不复制第三方源码。
- 初版只支持偶数FFT、H=N/2，周期Hann分析窗和同窗合成，以累加窗平方逐点归一化。暂不支持其他hop，输入时明确拒绝。
- 左侧补N/2个已知零，从起点−N/2开始分帧，只有完整帧到达才处理。首个有效输出hop需要N个真实样本到达；后续每H个样本释放一块。输出文件索引已去左padding，不表示系统零延迟。
- 尾部只有明确flush后才补零，按原始总样本数裁剪。重置、重复flush、丢块和乱序均有明确行为。
- 同时保留独立的SciPy离线STFT交叉验证，换算它的窗和归一化约定；未把legacy stft作为生产处理链。
- 单边谱的DC/Nyquist保持实数；DAS权重在这两个频点取实部。M1输出不硬截500～5000Hz，评价同时给全带和带内数值。
- 传播输入由独立的时域窗化sinc生成，而非在同一STFT上乘steering；解析正弦测试独立检查增益、方向和通道反接。

## 限制

窗化sinc仿真使用129 taps、Kaiser beta=8.6、信号区间外零延拓，属于离线输入生成，不是板端延迟滤波器。有限STFT窗的逐频点相移不等于精确时域延迟，必须保留幅值失真/音质测试。

M1使用调幅带限独立噪声，避免未确认的语料许可依赖；这是工程检查，不是语音分离基准，不能据其一场结果宣布B1/B2达标。256/512点都保留，尚未冻结最终窗长。
