# beamforming

已实现DAS和固定几何最小范数约束；后者带rank/condition/WNG检查和DAS回退，未实现自适应协方差LCMV。数据语义见docs/架构与规范/接口与数据契约.md，进展见docs/实验与验证/M2真实语音开发基线.md。

v0.3.8支持可选距离的球面匹配DAS及固定约束，复用原求解/回退链；None保持平面行为。准确距离是开发oracle，自动估距未实现。

v0.3.10新增mpdr.py：只用混合PCM完整帧估计xxᴴ，trace相对加载及单目标直接响应；含目标统计称MPDR，未实现持续在线协方差更新。


sector_lcmv.py：每输出三个离散方向单位响应约束的加载LCMV候选。带内条件数/WNG回退可观察，不能声称连续扇区保证；是否采用以冻结开发对照为准。
