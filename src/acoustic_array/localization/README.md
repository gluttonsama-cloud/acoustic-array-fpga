# localization

`scan_directions` 对同步多通道复数谱帧 `[frame, frequency, microphone]` 做静态远场方向扫描，返回与严格递增的 `angles_deg` 网格对应的一维得分。角度限前半平面 `[-90°, 90°]`，正角朝阵列 `+x`；方向相位沿用 `core.geometry.steering_vectors`。函数不接收声源真值，也不进行文件 IO。

默认 `srp_phat` 先跨帧平均每对麦克风的互谱，再取相位与候选方向的麦对相位比较，输出有效频点和麦对的实数平均。`das` 输出各帧、有效频点延时求和后的平均功率。输入统一除以所选频带内最大复数分量幅度，使 DAS 得分对整体增益不变；SRP-PHAT 本身也对正的整体增益不变。两种得分不能相互比较，PHAT 得分不是概率。

扫描忽略 DC、Nyquist、频带外频点和能量低于 `relative_floor` 倍最强频点的频点；PHAT 还忽略低于最强麦对互谱幅度同一比例的麦对/频点。静音或没有有效频点、麦对时返回全零。`relative_floor` 是相对数值门槛，并非绝对噪声底。默认频带为 500–5000 Hz，配置边界须在 `[0, Nyquist]` 内。

`select_peaks` 独立从得分中提取局部峰，含边界峰；平台峰取中间网格点（偶数长度取靠小角的一点），全平坦扫描无峰。候选按得分降序、同分小角优先，逐一抑制小于 `minimum_separation_deg` 的邻峰，最多返回 `max_sources` 个 `DirectionPeak(angle_deg, score)`。`minimum_score` 必须由调用方按扫描方法和场景指定；没有过门槛的局部峰就返回空元组，不补足路数。

此模块只输出静态候选；得分不是可信度校准值，也不表示目标身份、运动跟踪或实时处理能力。正式定位效果须另做角误差、漏检、虚警和静音测试，并与多路音频增强效果分开评价。

## 短时方向候选（开发实现）

`temporal.temporal_candidates`在每帧做PHAT，再聚合完整短块空间图。局部峰先做显著性筛选，再按角距和上限选择；相邻角度三角投票，每块最多一票，跨所有块（包含静音）统计支持度。输出分数是支持比例，不是源存在概率。

返回`scores[angle]`、`block_scores[block,angle]`、`peaks`、`block_count`及实际使用的`frame_count`，不足一块的尾帧显式舍弃。当前为批量静态API，不保存跨调用状态，不宣称已有在线身份跟踪。真实端射可出现单侧峰，边界默认30°显著性邻域，内部默认10°。

短块PHAT消除幅度信息，因此微弱但相干输入仍可有高分；需要真实噪声/通道标定后才能讨论产品检出率和误报率。

## 时频子带主导方向（开发候选）

`subband.subband_candidates`把完整短块和连续频点子带组成候选单元。每个有能量的单元在逐帧PHAT后只保留一个足够显著的主导方向，再将全部单元的投票累积成方向直方图。这与从一张宽带图选多峰不同。

返回归一化投票、`[block,subband,angle]`谱、峰、实际使用帧/频点数和接受单元数。不完整尾块/尾子带明确丢弃，静音或不一致单元投零票但仍进入总单元分母。得分不是概率，也不是已校准的声源存在置信度。

## MUSIC外部参考（PC离线）

`music_reference.music_candidates`适配Pyroomacoustics 0.10.1的MUSIC与NormMUSIC。输入仍为项目`[frame,frequency,mic]`完整RFFT谱，适配为库`[mic,frequency,snapshot]`；项目角度从`+y`向`+x`，库方位角从`+x`起算，使用`phi=90°-theta`显式转换并恢复原网格顺序。

`num_sources`是信号子空间秩，当前固定开发基线显式使用3，不等于未知源数检测。所选频带按共同最大幅度缩放，未选频点清零，静音返回零分与空峰；输出谱归一到`[0,1]`后使用项目统一峰间隔规则。分数不是概率，库调用、PC运行时间和解析正确性都不构成FPGA资源或实时证据。

## 起音时频筛选

`onset.onset_filter`只读混合复数谱，输出原谱/零、时频掩码、增长dB与逐频保留计数。增长仅比较过去history帧，top-K使用完整观察窗，所以整体仍是批处理。前history帧不可选；不足minimum_snapshots的频点全部丢弃。它不是直达声标签生成器，也不能识别起音属于目标还是干扰。

`music_candidates`新增可选布尔`frequency_mask[F]`，与处理频带取交集，避免将被全部剔除的频点交给零协方差特征分解。无有效频点时返回空峰和零分；省略此参数保留旧接口行为。
