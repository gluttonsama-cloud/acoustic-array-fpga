# FPGA多声源空间分离与定向增强

仓库公开源码、配置、文档、验证摘要和小型硬件对接包。原始语料、用户提供的内部PDF/截图、完整实验音频与大型中间结果只保存在本地；文档中引用这些路径时，需要相应的本地资料才能复现或试听。请勿把仓库缺少的实录或板端结果视作已完成。

**技术核心：多声源实时空间分离＋定向拾音；重点演示：复杂噪声下弱声定向增强。** 搜救中的呼救/敲击属于应用示例，不将产品限死为搜救设备。详见[应用边界与转向条件](docs/规划与进度/主应用场景与转向条件.md)；后续顺序以[执行看板](docs/规划与进度/执行看板与续接规则.md)为准。

面向16麦线阵与Zynq-7020候选平台，建立算法参考、定点对照和硬件联调体系。软件包为`acoustic_array`，项目目录为`acoustic-array-fpga`。

**当前版本v0.3.10：M1基础完成，30场S1受控保留评价达到B1效果门槛。近场/混响、自动DOA、实录、定点与板端仍未验收。**

主512点方案带内场景中位数25.118dB、P10 23.094dB，30场无运行失败；全带仅7.021/4.112dB。结论限定于给定方向、理想远场、无混响，不代表弱声搜救或真实硬件能力。

## 当前进展

W3阵型仿真筛选及[四条件确认](docs/实验与验证/锁定阵型的四条件确认.md)完成。锁定交错布局相对原线阵的主MPDR全带改善收益中位为+3.908dB，最小+1.991dB，保留为优先可调实录候选。最困难的3米、15°间隔条件，全带改善仍仅1.155dB；这不是硬件定型或复杂环境验收。

W4已实现[十六通道录音文件回放入口](docs/实验与验证/十六通道录音回放联调.md)：显式坐标、通道映射、校准区间，人工角或带源数先验的自动候选，保留原始参考和异常状态。合成单源20°命令跑通，尚无新的真实录音成绩。此前起音输出及固定50%参考混合均未通过稳健性关口，停止比例/定位阈值扫描，硬件仍不冻结。

已有研究明确：固定几何零陷不宜作为当前室内默认方案；MPDR对方向误差敏感；[弱敲击三点约束候选](docs/实验与验证/弱敲击定向增强与三点约束对照.md)未通过门槛。完整历史证据见索引，W1/W2最终统计补丁的独立复核仍待补齐。

## 常用命令

在项目根目录执行；首次使用先按[运行环境与依赖](docs/架构与规范/运行环境与依赖.md)安装。

```powershell
.venv/Scripts/python.exe -m pytest -q
.venv/Scripts/python.exe -m acoustic_array.pipelines.cli --config configs/experiments/m1_das.json
```

已完成的S1评分命令见其报告；不要根据保留集结果择优调参。本轮全仓414项测试通过；录音入口及前轮小补丁的Sol独立审查通过。
